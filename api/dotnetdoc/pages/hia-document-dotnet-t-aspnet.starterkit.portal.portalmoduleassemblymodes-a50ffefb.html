模块装配态的封闭两值：生产预编译态与受控调试态。

Closed two-value vocabulary for module assembly modes: the production precompiled mode and the controlled debug mode.

remarks

取值一经写入台账、迁移记录与文档即成为稳定契约，不得重命名；本类只定义词表，不判断当前环境是否允许调试态，也不执行装配动作。

These values become a stable contract once written into the ledger, migration records, and documentation, and must not be renamed; this class defines the vocabulary only, judges no environment permission, and performs no assembly action.
