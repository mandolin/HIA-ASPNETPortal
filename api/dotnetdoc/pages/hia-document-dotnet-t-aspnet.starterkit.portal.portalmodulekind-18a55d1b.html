模块承载形态：区分本体核心模块与本体之外以独立能力模块形式提供的模块。

Module hosting form: distinguishes core portal modules from modules provided externally as independent capability modules. 已验证的受信任部署模块包元数据。 Metadata for a validated trusted-deployment module package.
