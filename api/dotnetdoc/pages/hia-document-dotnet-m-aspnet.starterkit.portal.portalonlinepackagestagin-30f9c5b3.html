dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalOnlinePackageStaging.TryStage(string archivePath, string isolationRoot, out string extractedDirectory, out string reason)

把一个 ZIP 包安全解压到隔离根目录下的全新子目录；任何失败都不留下半解压内容。

Safely extracts a ZIP into a fresh subdirectory beneath the isolation root; no failure leaves partially extracted content behind.

Localized Fields

remarks

调用方须先完成上传白名单与权限校验；本方法不实施页面授权，也不验证清单语义（由 manifest v2 解析链在后续包负责）。 返回的隔离子目录由调用方负责在「确认安装」或「放弃」后清理，本类只在失败路径上自动清理。

Callers must complete upload allow-list and authorisation checks first; this method enforces no page authorisation and does not validate manifest semantics (the manifest v2 parser owns that in later packages). The returned isolated directory is cleaned up by the caller after "confirm install" or "discard"; this class cleans up automatically only on the failure path.

params.archivePath.summary

已落地的包压缩文件绝对路径。

Absolute path of the landed compressed package file.

params.isolationRoot.summary

应用自控的隔离根目录绝对路径，不得为 null 或相对路径。

Absolute path of the application-controlled isolation root; must not be null or relative.

params.extractedDirectory.summary

成功时为新建的隔离子目录绝对路径，失败时为 null。

On success, the absolute path of the new isolated subdirectory; null on failure.

params.reason.summary

失败原因的稳定短语，不回显不可信条目名；成功时为空字符串。

Stable failure phrase that never echoes untrusted entry names; empty on success.

returns.summary

整包解压成功且清单存在时为 true。

True when the whole archive extracted successfully and the manifest is present.
