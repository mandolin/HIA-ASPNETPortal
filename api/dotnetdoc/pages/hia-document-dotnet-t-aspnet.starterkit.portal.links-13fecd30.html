Links

dotnet-type.NET
class ASPNET.StarterKit.Portal.Links

显示链接列表，并隔离旧记录中不再符合地址策略的链接。 链接展示用户控件的 Designer 字段容器；字段由 ASCX 服务器控件生成。

Renders the link list and isolates legacy links that no longer pass URL policy. Designer field container for the links display user control; fields are generated from ASCX server controls.

Localized Fields

remarks

普通浏览路径只输出通过 `PortalNavigationPolicy` 的地址；编辑者仍进入站内编辑页，以便修复历史不合规链接。

The browse path outputs only URLs accepted by `PortalNavigationPolicy`; editors still enter the internal edit page so legacy non-compliant links can be repaired.
