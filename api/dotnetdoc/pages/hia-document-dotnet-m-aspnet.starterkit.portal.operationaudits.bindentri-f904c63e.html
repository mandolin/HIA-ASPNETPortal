private void ASPNET.StarterKit.Portal.OperationAudits.BindEntries()

按当前日期和文本筛选条件查询并绑定运营审计记录。

Queries and binds operations-audit records using the current date and text filters.

Localized Fields

remarks

日期解析失败时清空旧结果；成功后将页码、固定页大小和受控筛选值交给只读审计查询，并把存储不可用作为明确回退。

Invalid dates clear stale results; valid dates pass the page, fixed page size, and controlled filters to the read-only audit query, treating unavailable storage as an explicit fallback.
