为动态加载的桌面模块提供 Portal/模块上下文、编辑入口提示、设置懒加载和当前请求依赖注入的基类。

Base class providing Portal/module context, edit-entry hints, lazy settings loading, and current-request dependency injection to dynamically loaded desktop modules.
