IsProtectedAdministrationTabName

dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalAdministrationPolicy.IsProtectedAdministrationTabName(string tabName, string navigationKey)

按**导航稳定键**（优先）或显示名称（回退）判断 Tab 是否为受保护的核心后台 Tab。

Decides whether a Tab is the protected core administration Tab by its **navigation stable key** (preferred) or display name (fallback).

Localized Fields

remarks

为什么必须引入稳定键：页签名（`TabName`）已支持多语言，显示名会随界面文化改变甚至被管理员改成中文， 而"后台入口保护""禁止重命名""后台 Tab 排到最后"这些策略都按名识别。若继续按显示名判定， 把 Admin 改成"后台管理"的那一刻，保护就会静默失效 —— 这正是页签名本地化最危险的连带破坏点。 迁移脚本 `PortalCfg_TabModuleMultilingualNames.sql` 已把既有页签名回填为稳定键，因此存量部署零回归。

Why a stable key is required: tab names (`TabName`) are now multilingual, so the display name changes with the UI culture and can even be renamed to Chinese by an administrator, while "administration entry protection", "rename blocked", and "keep the administration Tab last" all recognize by name. If recognition stayed on the display name, the moment `Admin` became "后台管理" the protection would silently stop working — the most dangerous knock-on effect of localizing tab names. Migration `PortalCfg_TabModuleMultilingualNames.sql` backfills existing tab names as stable keys, so existing deployments regress not at all.
