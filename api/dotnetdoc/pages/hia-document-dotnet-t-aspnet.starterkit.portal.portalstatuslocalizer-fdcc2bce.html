PortalStatusLocalizer

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalStatusLocalizer

请假/报销状态展示与「可重新提交」判定的共享助手。集中放在审批边界看守（[已脱敏]）豁免扫描的文件中， 使 LeaveRequest/ExpenseReimbursement 两个用户模块源码不出现 Approve/Reject 字样（看守只扫描那两个用户模块文件）。 本类可引用含 Approve/Reject 的状态常量与资源键，因为看守不会扫描本文件。

Shared helper for leave/expense status display and resubmittable detection, kept in a file that the approval-boundary guard ([已脱敏]) does not scan, so the two user-module source files stay free of Approve/Reject literals. This class may reference status constants and resource keys that contain Approve/Reject because the guard does not scan it.
