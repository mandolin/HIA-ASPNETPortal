ShouldRevokeForSecurityVersionMismatch

dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalAuthenticationService.ShouldRevokeForSecurityVersionMismatch(long ticketSecurityVersion, long databaseSecurityVersion, bool ticketSecurityVersionReadable)

纯函数化的签退决策，供 Application_AuthenticateRequest 与回归测试共用。票据不可读，或数据库安全版本可确定（>0）且与票据不符时返回 true；数据库版本为 0 表示“无法判定”（瞬态读取失败、旧库无 Portal_UserSecurityStates 状态表、或状态行缺失），必须返回 false，否则单例 DbContext 上的并发查询竞态会使读取偶发失败返回 0，把活跃会话随机踢出（P42 修复）。

Pure revoke decision shared by Application_AuthenticateRequest and regression tests. Returns true when the ticket is unreadable, or the database security version is determinable (>0) and differs from the ticket; a database version of 0 means "undetermined" (transient read failure, a legacy DB without the Portal_UserSecurityStates table, or a missing state row) and must return false, otherwise concurrent queries on the singleton DbContext would intermittently return 0 and randomly sign out active sessions (P42 fix).
