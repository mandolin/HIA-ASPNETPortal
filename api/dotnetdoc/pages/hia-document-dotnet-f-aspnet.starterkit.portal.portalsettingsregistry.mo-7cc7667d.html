ModuleAssemblyAllowCodeFile

dotnet-field.NET
public static readonly ASPNET.StarterKit.Portal.PortalSettingDefinition ASPNET.StarterKit.Portal.PortalSettingsRegistry.ModuleAssemblyAllowCodeFile

控制是否允许装配态台账出现受控调试态的部署级只读设置定义，默认关闭。

Deployment-level read-only setting definition controlling whether the assembly-state ledger may contain the controlled debug mode; disabled by default.

Localized Fields

remarks

requiresRestart 为 true 且 canEditOnline 为 false：仅部署侧 appSettings 可提供该值，数据库覆盖层与请求值都不是合法来源；本定义不实施页面授权。

requiresRestart is true and canEditOnline is false: only deployment-side appSettings may supply the value; neither the database override layer nor request values are legitimate sources. This definition implements no page authorization.
