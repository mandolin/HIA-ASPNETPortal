public static string ASPNET.StarterKit.Portal.PortalEmptyStateRenderer.Render(int? rowCount, string message, int columnCount)

渲染零条记录时的表格内提示行；有数据或调用方要求抑制时返回空字符串。

Renders the in-table hint row for a zero-row result; returns an empty string when rows exist or when the caller asks to suppress it.

Localized Fields

params.rowCount.summary

列表已渲染的行数：大于 0 表示有数据，等于 0 表示"查询成功但没有记录"，表示**抑制空态**——调用方处在失败或不可用路径（此时页面已给出错误提示，再渲染"暂无"会把故障说成没有数据）。仅当表体在失败时仍然可见（例如后台页只清空列表、不隐藏表格）才需要传；失败时整块区域被隐藏的调用方传 0 即可。 null null

The number of rows already rendered: greater than zero means data exists, zero means "the query succeeded with no records", andmeans **suppress the empty state** because the caller is on a failure or unavailable path (the page already shows an error, and rendering "nothing here" would present a fault as absent data). Passonly where the table body stays visible on failure (for example an Admin page that merely clears the list without hiding the table); callers that hide the whole area on failure can pass 0. null null

The hint wording chosen by the caller for "no data" or "no matches"; it is HTML-encoded before output and blank values degrade to empty text.
