interface ASPNET.StarterKit.Portal.IRoleItem

旧门户角色项契约。

Contract for a legacy portal role item.

Localized Fields

remarks

该接口用于后台角色列表、模块编辑角色选择和用户角色分配。角色名称仍为旧角色体系的显示/匹配值； 权限判断应通过统一授权服务或角色解析工具完成，不应只依赖页面局部字符串比较。

This interface is used by administration role lists, module edit-role selectors, and user role assignment. Role names remain display/matching values from the legacy role system; authorization should go through shared authorization services or role parsing helpers instead of page-local string comparison alone.
