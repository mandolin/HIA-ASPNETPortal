MatchesDeclaredContentType

dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalOnlinePackagePolicy.MatchesDeclaredContentType(string contentType)

对 MIME 类型做快速一致性提示；返回 false 不表示文件恶意，仅表示与预期包类型不符。

Provides a quick MIME consistency hint; a false result does not imply malice, only a mismatch with the expected package type.

Localized Fields

remarks

OWASP 明确 Content-Type 可伪造、不得作为安全依据；本方法只用于给管理员一个早期提示， 真正的类型判定由扩展名白名单与后续签名/扫描完成，调用方不得用本方法结果放行文件。

OWASP states Content-Type is spoofable and must not be a security basis; this method only gives administrators an early hint, while the real type decision belongs to the extension allow-list and later signature/scanning. Callers must not use its result to accept a file.

params.contentType.summary

浏览器声明的 Content-Type，可为 null。

Browser-declared Content-Type; may be null.

returns.summary

等于 application/zip（忽略大小写）时为 true。

True when it equals application/zip, ignoring case.
