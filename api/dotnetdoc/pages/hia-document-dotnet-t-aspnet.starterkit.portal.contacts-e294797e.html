Contacts

dotnet-type.NET
class ASPNET.StarterKit.Portal.Contacts

渲染当前模块的只读联系人列表。 联系人展示用户控件的 Designer 字段容器；字段由 ASCX 服务器控件生成。

Renders the read-only contact list for the current module. Designer field container for the contacts display user control; fields are generated from ASCX server controls.

remarks

联系人姓名、角色、电话等普通字段由 ASCX 标记层编码输出；邮件链接只在存在非空地址时生成URL，本控件不承担邮箱格式校验。 mailto:
