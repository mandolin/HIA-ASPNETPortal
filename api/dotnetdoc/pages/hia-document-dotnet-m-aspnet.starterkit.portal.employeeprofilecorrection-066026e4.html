TryCompleteWorkItem

dotnet-method.NET
private void ASPNET.StarterKit.Portal.EmployeeProfileCorrectionRequests.TryCompleteWorkItem(long requestId, string requestStatus, string reviewNote)

尝试把资料更正处理结果同步到轻量待办。

Attempts to mirror the profile-correction review result into lightweight work items.

Localized Fields

remarks

待办是审核通过后的旁路增强能力：本方法只在待办依赖为空或请求标识非正数时短路，其余情况一律调用待办服务；调用失败会被捕获并降级（记录诊断日志），不影响"审核已成功、请求状态已更新"这一主流程结果。

Work items are a sidecar enhancement after a successful review: this method short-circuits only when the work-item dependency is absent or the request identifier is non-positive; otherwise it always calls the work-item service, but a failure is caught and degraded (diagnostic log only) so it never rolls back the main "review succeeded, request status updated" result.
