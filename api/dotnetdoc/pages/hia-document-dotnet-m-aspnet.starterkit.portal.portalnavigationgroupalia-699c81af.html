TryResolveGroup

dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalNavigationGroupAlias.TryResolveGroup(string navigationKey, string configuration, out ASPNET.StarterKit.Portal.PortalNavigationGroupAlias.GroupDefinition definition, out bool degraded)

解析一个页签的分组归属：先看部署别名覆盖，再看词表默认成员；未知页签返回 false（调用方按未分组平铺展示， 绝不隐藏）。配置解析失败时同样回退默认词表，保证「别名解析失败 → 一级平铺」的降级路径永不丢页签。

Resolve one tab's group: deployment alias override first, then vocabulary default membership; an unknown tab returns false and the caller renders it ungrouped (never hidden). A failed configuration parse also falls back to defaults, so the "alias parse failed → flat navigation" degradation path never loses a tab.
