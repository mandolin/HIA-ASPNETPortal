CreateIsolatedDirectoryName

dotnet-method.NET
public static string ASPNET.StarterKit.Portal.PortalOnlinePackagePolicy.CreateIsolatedDirectoryName()

为一次上传生成全新的、应用自控的隔离子目录名。

Generates a fresh, application-controlled isolated subdirectory name for one upload.

Localized Fields

remarks

Microsoft Learn 要求不受信任归档解压到「全新的、应用自控的目录」，因为目标目录或其父级若已存在 junction/符号链接， 即便路径断言通过仍会写到链接之外；每次上传使用新目录可把该风险限制在单次操作，且失败时可按目录整体清理。

Microsoft Learn requires untrusted archives to be extracted into a fresh, application-controlled directory, because an existing junction or symbolic link in the destination or a parent can redirect writes outside even when path assertions pass; a new directory per upload confines that risk to one operation and allows whole-directory cleanup on failure.

returns.summary

形如 pkg- 加 32 位十六进制小写串的目录名。

A directory name such as pkg- plus a 32-character lowercase hex string.
