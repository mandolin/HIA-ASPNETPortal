GroupTab_ItemDataBound

dotnet-method.NET
protected void ASPNET.StarterKit.Portal.DesktopPortalBanner.GroupTab_ItemDataBound(object sender, System.Web.UI.WebControls.RepeaterItemEventArgs e)

给禁用态补 `aria-disabled`：Web Forms 的 `asp:Label` 不会自动写该属性， 而可见性绑定只控制 DOM 是否输出，两者职责不同，故在 ItemDataBound 里补一次。

Add `aria-disabled` to the disabled state: the Web Forms `asp:Label` does not emit it automatically, while the visibility binding only controls whether the DOM is emitted. The two concerns are distinct, so this handler adds the attribute once at ItemDataBound.
