PortalOnlinePackageConfirmationGate

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalOnlinePackageConfirmationGate

在线能力包双步确认闸：签发一次性票据，并在「确认安装」时执行二次鉴权、防伪令牌、包哈希绑定、过期与防重放判定。

Two-step confirmation gate for online capability packages: issues a one-time ticket and, at "confirm install", enforces re-authorization, anti-forgery token, package-hash binding, expiry, and replay defence.

remarks

本类型是**纯逻辑、无状态**的判定器：不读取 HTTP 请求、不读写数据库、不持有票据存储、不加载程序集。 页面层负责在上传成功后持久化票据、在确认时取回并回传；持久化介质（会话/数据库）由后续独立能力模块接线。 依据 OWASP CSRF Prevention Cheat Sheet 的同步令牌模式与 DNN「上传 ZIP → 逐页展示包信息 → 显式接受后才安装」的分步向导。 **A 级硬边界**：闸只接受 `PortalPermissionKeys.ModuleOnlinePackageUpload` / `ModuleOnlinePackageConfirm` 两个已登记键的判定结果， 不接受来源声明、capability 声明或角色名作为授权依据；不授予 `Admins`，也不扩大任何角色的作用域。

This type is a **pure, stateless** decision maker: it reads no HTTP request, touches no database, holds no ticket store, and loads no assembly. The page layer persists the ticket after a successful upload and retrieves it for confirmation; the persistence medium (session/database) is wired by a later independent capability module. It follows the synchroniser-token pattern of the OWASP CSRF Prevention Cheat Sheet and DNN's wizard ("upload ZIP, review package information page by page, install only after explicit acceptance"). **A-level hard boundary**: the gate accepts only verdicts for the two registered keys `PortalPermissionKeys.ModuleOnlinePackageUpload` / `ModuleOnlinePackageConfirm`; no origin claim, capability claim, or role name is an authorization basis; it grants no `Admins` role and extends no role's scope.
