PortalOnlinePackageUnavailableScanner

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalOnlinePackageUnavailableScanner

「未接线」扫描器的显式实现：恒定返回 `Unavailable`，用于让「没有扫描器」成为可见的拒绝原因， 而不是 null 或默认 `Clean`。这是 Q3「可降级、fail-closed」的默认落地。

Explicit "unwired" scanner implementation: always returns `Unavailable`, so "no scanner" becomes a visible rejection reason rather than null or a default `Clean`. This is the default realization of Q3's "degradable, fail-closed" rule.
