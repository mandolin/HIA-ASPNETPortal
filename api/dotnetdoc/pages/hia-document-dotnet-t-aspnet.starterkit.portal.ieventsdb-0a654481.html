interface ASPNET.StarterKit.Portal.IEventsDb

事件内容模块的数据访问契约。

Data-access contract for event content modules.

Localized Fields

remarks

该契约沿用旧事件模块的存储语义：过期时间用于列表过滤，地点/时间说明作为展示文本保存。调用方负责模块编辑权限、条目归属、日期解析和低敏校验提示。

This contract keeps the legacy events module storage semantics: expiration time is used for list filtering, while the where/when value is stored as display text. Callers own module-edit authorization, item ownership checks, date parsing, and low-sensitivity validation messages.
