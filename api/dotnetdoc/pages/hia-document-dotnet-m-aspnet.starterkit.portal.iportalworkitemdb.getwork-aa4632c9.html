GetWorkItemEvents

dotnet-method.NET
System.Collections.Generic.IList<ASPNET.StarterKit.Portal.PortalWorkItemEventInfo> ASPNET.StarterKit.Portal.IPortalWorkItemDb.GetWorkItemEvents(long workItemId, int take)

读取指定待办最近发生优先的事件快照。

Reads a newest-occurrence-first event snapshot for the specified work item.

Localized Fields

remarks

待办标识只用于查询定位，不证明调用方可查看对应业务对象。返回事件是可变历史投影，不能替代当前状态或授权事实。当前实现对非法标识、架构不可用或查询异常均返回空列表。

The work-item identifier is only a query locator and does not prove that the caller may view the associated business object. Returned events are mutable historical projections and cannot replace current-state or authorization facts. The current implementation returns an empty list for invalid identifiers, unavailable schema, and query failures.

params.workItemId.summary

正数待办标识；非正数返回空列表。

Positive work-item identifier; a non-positive value yields an empty list.

params.take.summary

期望最大条数；当前实现对非正数使用 20，并把上限限制为 200。

Requested maximum row count; the current implementation uses 20 for non-positive values and caps the count at 200.

returns.summary

最近发生优先的可变事件投影列表；非法输入或读取失败时也可为空。

A mutable newest-occurrence-first list of event projections, which may also be empty for invalid input or read failures.
