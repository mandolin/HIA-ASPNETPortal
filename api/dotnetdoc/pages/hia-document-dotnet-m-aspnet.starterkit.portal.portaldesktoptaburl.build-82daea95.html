public static string ASPNET.StarterKit.Portal.PortalDesktopTabUrl.Build(string applicationPath, int tabIndex, int tabId)

构造指向指定页签的桌面地址。

Builds a desktop URL pointing at the specified tab.

Localized Fields

params.applicationPath.summary

应用相对路径前缀（可含虚拟目录）；为空时按根站点处理。

The application-relative path prefix (which may include a virtual directory); blank means the site root.

params.tabIndex.summary

页签在门户桌面列表中的下标，仅影响匿名登录模块的注入启发式。

The tab's index in the portal desktop list; it only affects the anonymous-login injection heuristic.

params.tabId.summary

页签标识，目标页校验的授权真源。

The tab identifier, the authorization source of truth validated by the target page.

returns.summary

应用相对的可导航地址；数值一律用固定区域性格式化，避免本地化数字分隔符进入 URL。

An application-relative navigable URL; numbers always use invariant formatting so localized digit separators never enter the URL.
