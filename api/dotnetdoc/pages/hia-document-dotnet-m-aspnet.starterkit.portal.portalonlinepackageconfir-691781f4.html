public static bool ASPNET.StarterKit.Portal.PortalOnlinePackageConfirmationGate.TryIssue(string actorName, string packageStorageName, string packageHash, System.DateTime issuedUtc, string uploadPermissionKey, bool uploadGranted, out ASPNET.StarterKit.Portal.PortalOnlinePackageConfirmationTicket ticket, out string reason)

在上传校验通过且已判定具备上传权限后，签发一次性确认票据。

Issues a one-time confirmation ticket after upload validation passed and upload permission was granted.
