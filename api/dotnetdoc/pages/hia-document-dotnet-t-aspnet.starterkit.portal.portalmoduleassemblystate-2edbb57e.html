class ASPNET.StarterKit.Portal.PortalModuleAssemblyState

独立部署侧装配态台账的只读快照：按稳定包标识保存已显式登记的装配态。

Read-only snapshot of the deployment-side module-assembly state ledger, holding explicitly registered modes keyed by stable package identifier.

Localized Fields

remarks

台账是装配态的唯一事实源，与包启用状态、能力归属、Profile gate 严格分离；无条目的包按受控缺省视为 CodeBehind。本类型不读取文件、数据库或 HTTP 请求，也不写回任何来源。

The ledger is the single source of truth for assembly mode and stays strictly separate from package enablement, capability ownership, and the Profile gate; a package without an entry uses the controlled CodeBehind default. This type reads no file, database, or HTTP request and writes back to no source.
