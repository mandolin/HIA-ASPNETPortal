class ASPNET.StarterKit.Portal.RolePermissionEntry

角色与权限键映射的只读投影，用于能力权限矩阵的展示。

Read-only projection of a role-to-permission-key mapping, used by the capability permission matrix.

Localized Fields

remarks

本类型是查询结果载体，不是领域实体：它不表达"已授权"的最终结论（`IsEnabled` 只表示该映射是否生效），也不提供任何写入路径。属性使用公共 setter 是为了适配既有的 SqlQuery 投影方式。

This type is a query-result carrier rather than a domain entity: it does not represent a final authorization conclusion (`IsEnabled` only states whether the mapping is effective) and exposes no write path. Public setters exist to fit the established SqlQuery projection style.
