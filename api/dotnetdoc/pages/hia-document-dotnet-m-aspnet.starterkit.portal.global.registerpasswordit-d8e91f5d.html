注入密码哈希目标迭代次数提供器。

Registers the password-hash target iteration-count provider.

Localized Fields

remarks

位于独立组件项目，不能反向依赖 Web 配置读取器；因此启动期通过委托注入当前目标迭代次数。读取失败或配置低于硬下限时，策略类自身会回退到硬下限 210000。

lives in the independent components project and must not depend back on the Web configuration resolver, so startup injects a delegate for the target iteration count. The policy class falls back to its hard lower bound of 210000 if reads fail or configuration is lower.
