class ASPNET.StarterKit.Portal.PortalContext

统一管理当前请求中的 PortalSettings，集中固定 Items 键名、上下文回退和缺失异常边界。

Centralizes the current request's PortalSettings contract, including the Items key, context fallback, and missing-context exception boundary.
