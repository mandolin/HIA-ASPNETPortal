PortalOnlinePackageSecurityGate

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalOnlinePackageSecurityGate

在线能力包安全闸门：把「包级白名单 + SHA-256 完整性 + RSA-SHA256 签名（可选）+ 恶意扫描」四道判据 联合成**唯一放行入口**，任一不满足即拒绝（Q3 三系统联合判定 + 完整性前置）。纯逻辑、无状态、不触 IO。

Security gate for online capability packages: combines package allow-list, SHA-256 integrity, optional RSA-SHA256 signature, and malware scanning into the **single allow decision**; any failing criterion rejects. Pure, stateless, no IO.

Localized Fields

remarks

判定顺序固定：请求/内容 → 白名单 → 完整性 → 签名 → 扫描；每一步都在不产生副作用前完成。 签名可选语义：`requireSignature=true` 但公钥/签名缺失即拒绝；`requireSignature=false` 时若仍提供了签名材料， 则**必须验签通过**，否则拒绝——避免伪造签名被静默忽略。扫描器为 null、抛异常或返回 `Unavailable` 一律拒绝（fail-closed）。 **A 级硬边界**：期望哈希、公钥均来自服务端受信任来源，接口不提供任何「从包内声明推导信任」的入口。

The order is fixed: request/content → allow-list → integrity → signature → scan; every step completes before any side effect. Optional-signature semantics: `requireSignature=true` with missing key/signature rejects; with `requireSignature=false`, supplied signature material must still verify, so a forged signature is never silently ignored. A null scanner, an exception, or an `Unavailable` verdict all reject (fail-closed). **A-level hard boundary**: expected hash and public key come from trusted server sources; the API offers no way to derive trust from package-declared claims.
