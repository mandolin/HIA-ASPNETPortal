ExternalConnectionStringLoader

dotnet-type.NET
class ASPNET.StarterKit.Portal.Util.ExternalConnectionStringLoader

从仓库外部加载门户主数据库连接串。

Loads the Portal primary-database connection string from outside the repository.

Localized Fields

remarks

真实连接串不得进入仓库，Unity 配置只保留依赖名称。启动时先读取外置文件中的逻辑连接串，再注册为旧数据访问层仍使用的 Unity 命名实例。 Portal connectionString

Real connection strings must not enter the repository; Unity configuration retains only a dependency name. Startup reads the logical externalconnection string, then registers it as the legacy Unity named instance. Portal connectionString
