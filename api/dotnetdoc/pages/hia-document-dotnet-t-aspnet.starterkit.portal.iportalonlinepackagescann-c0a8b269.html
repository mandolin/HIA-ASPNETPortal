IPortalOnlinePackageScanner

dotnet-type.NET
interface ASPNET.StarterKit.Portal.IPortalOnlinePackageScanner

在线能力包恶意扫描适配点。适配层只回答三值判定，不执行安装、不读取配置、不引入任何扫描引擎依赖。

Adapter point for online capability package malware scanning. The adapter only answers a three-value verdict; it performs no installation, reads no config, and introduces no scanning-engine dependency.

Localized Fields

remarks

Q3 裁定「封装可降级、fail-closed、扫描器留适配点、不强制引入重依赖」。因此本接口是唯一切入点： 企业内网可接入既有扫描器或外部服务；未接线时调用方传入返回 `Unavailable` 的实现，判定门据此拒绝， **不会**因为「还没接扫描器」而默认放行。适配层抛出的异常由判定门统一收敛为 `Unavailable`。

Q3 rules "degradable, fail-closed, leave a scanner adapter point, do not force heavy dependencies". This interface is the only hook: an enterprise network may wire an existing scanner or external service; when unwired, callers pass an implementation returning `Unavailable` and the gate rejects, so a missing scanner never defaults to allow. Exceptions from the adapter are converged to `Unavailable` by the gate.
