IsGroupTabLinkVisible

dotnet-method.NET
protected bool ASPNET.StarterKit.Portal.DesktopPortalBanner.IsGroupTabLinkVisible(object dataItem)

普通链接仅在「非选中且未被 gate 禁用」时可见；其余两种形态由各自的可见性方法承担， 三者互斥，保证一个页签只渲染一种形态。

A normal link is visible only when the tab is neither selected nor gate-disabled; the other two forms have their own visibility helpers. The three are mutually exclusive, so each tab renders exactly one form.
