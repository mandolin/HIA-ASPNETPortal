interface ASPNET.StarterKit.Portal.IDocumentItemDetails

包含历史数据库二进制内容的文档模块详情契约。

Document-module detail contract that includes legacy database binary content.

Localized Fields

remarks

当前项目不再写入此二进制内容；它只为已有记录下载兼容保留，输出时必须作为附件处理，并由下载页重新决定文件名、MIME 类型和缓存策略。

The project no longer writes this binary content; it remains only for existing-record download compatibility, must be emitted as an attachment, and lets the download page decide file name, MIME type, and caching policy again.
