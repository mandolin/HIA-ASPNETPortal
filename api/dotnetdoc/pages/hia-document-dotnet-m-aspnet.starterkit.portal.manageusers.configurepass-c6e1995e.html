private void ASPNET.StarterKit.Portal.ManageUsers.ConfigurePasswordSubmission()

按加密开关配置管理员重置密码提交脚本。

Configures administrator password-reset submission scripts from the encryption switch.

Localized Fields

remarks

加密开关只决定客户端脚本和服务端提交载体；脚本 URL 经过现有 JavaScript 编码，服务端仍必须在回发中验证密文完整性，不能把前端加密当作授权。

The encryption switch controls only the client script and server submission carrier; script URLs use the existing JavaScript encoding, and the server must still validate encrypted fields on postback, so client encryption is not authorization.
