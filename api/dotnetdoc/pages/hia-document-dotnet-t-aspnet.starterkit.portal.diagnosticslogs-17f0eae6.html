class ASPNET.StarterKit.Portal.DiagnosticsLogs

只读结构化诊断日志查询页面。

Read-only structured diagnostics log query page.

Localized Fields

remarks

页面只读取已经由诊断查询服务投影的低敏事件，不创建日志、不执行任意文件读取，并通过固定页大小和日期范围限制查询成本。

The page reads only low-sensitivity events projected by the diagnostics query service; it does not create logs or read arbitrary files, and bounds query cost with a fixed page size and date range.
