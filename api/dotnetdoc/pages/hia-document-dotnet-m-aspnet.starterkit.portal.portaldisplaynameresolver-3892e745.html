private static bool ASPNET.StarterKit.Portal.PortalDisplayNameResolver.TryGetJsonValue(string localizedJson, System.Globalization.CultureInfo culture, out string value, out string error)

从其它语言 JSON 列中按"完整文化名 → 父文化名 → 两字母码"三级取回该文化的文本。

Retrieves the text for a culture from the other-languages JSON column using the three-tier lookup "full culture name → parent culture name → two-letter code".

Localized Fields

remarks

解析失败一律走"未命中 + 原因"，绝不抛出：JSON 列由管理员手填，允许出现数组、嵌套或键名拼错， 这些都应表现为"回落到默认语言"，而不是把门户页头打成错误页。 键比较使用大小写不敏感：文化名的大小写差异（`ja-jp` 与 `ja-JP`）不应导致取不到值。

A parse failure always becomes "no hit plus a reason" and never throws: the JSON column is hand-edited by administrators, so arrays, nesting, or mistyped keys can occur, and all of them should degrade to the default language rather than turning the portal header into an error page. Key comparison is case-insensitive: casing differences in culture names (`ja-jp` versus `ja-JP`) must not lose the value.
