PortalModuleProvisioner

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalModuleProvisioner

独立模块安装/卸载机制的可复用实现，基于门户结构配置上下文执行幂等 SQL。 安装把模块定义、页签/模块实例与包状态写入 PortalCfg_* 表，使容纳机制（可信目录 + Profile 形态感知 + 状态表 IsEnabled）能实际装载运行； 卸载做反向清理且不残留。与 [已脱敏] 的 Form Builder 模块包配合，构成 R2「本体之外提供的能力」证据闭环的安装/卸载两端。

Reusable implementation of the independent-module install/uninstall mechanism, executing idempotent SQL against the portal structural configuration context. Install writes the module definition, tab/module instance and package state into the PortalCfg_* tables so the hosting mechanism (trusted catalog + profile shape awareness + state-table IsEnabled) can actually load and run the module; uninstall reverses the cleanup without residue. Together with the [已脱敏] Form Builder module package it closes the R2 evidence loop for capabilities provided externally.
