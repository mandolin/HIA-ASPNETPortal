remarks

P10.3 第一版固定使用 2048 位一次性密钥；后续会按客户端浏览器环境选择加密强度。 私钥只保存在当前 Session 中，并在口令提交时一次性消费，不写入日志、数据库或页面。

The first P10.3 version uses a fixed 2048-bit one-time key; later work will select encryption strength by client browser capability. The private key stays only in the current Session and is consumed once by the password post. It is never written to logs, the database, or the page.
