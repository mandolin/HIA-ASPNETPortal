class ASPNET.StarterKit.Portal.QuickLinks

显示快捷链接，并隔离不符合当前地址策略的历史链接。

Renders quick links and isolates legacy links that do not pass the current URL policy.

Localized Fields

remarks

快捷链接与普通链接共享地址策略；不同之处是它还会在模块内呈现编辑者新增入口。

Quick Links share the same URL policy as regular Links; the difference is that they also render an in-module add action for editors.
