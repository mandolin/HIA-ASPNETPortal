class ASPNET.StarterKit.Portal.PortalWorkItemTargetResolver

把待办的业务类型反查为普通用户在**当次请求**下有权限访问的承载页签。

Resolves a work item's business kind into the hosting tab that the ordinary user may access in the current request.

remarks

反查链：业务类型 → 能力键 → 主责模块包 → 已验证桌面入口 → 模块定义 → 模块实例 → 承载页签 → **角色检查**。链路每一环都可能是"部署未挂载""注册缺失"或"当前用户无权"，因此每一环都返回独立原因码而不是抛错或猜测地址；只有全链通过才产出可导航目标。**不扩权**：解析只读取既有注册与角色事实，不授予任何权限，也不改写模块或页签配置。

Reverse lookup chain: business kind to capability key to primary module package to validated desktop entry to module definition to module instance to hosting tab to a role check. Every link may fail because the deployment has not mounted the module, the registration is missing, or the current user lacks access, so each link returns its own reason code instead of throwing or guessing a URL; only a fully passing chain yields a navigable target. No privilege is widened: resolution reads existing registration and role facts, grants nothing, and rewrites no module or tab configuration.
