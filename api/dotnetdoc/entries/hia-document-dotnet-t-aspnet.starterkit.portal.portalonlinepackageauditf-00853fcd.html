class ASPNET.StarterKit.Portal.PortalOnlinePackageAuditFormatter

在线能力包审计载荷的六要素结构化紧凑格式器（纯函数，不依赖 Web 上下文、不连接数据库、不执行安装）。 固定键序与既有 `PortalModuleAssemblyAuditFormatter` 及离线工具 `Invoke-PortalModuleAssemblyCheck.ps1` 完全一致， 使装配态与在线包两类产物可互相印证；载体同为该表的 Summary 列。本类只格式化，不写入。

Structured compact formatter for the six-element online-package audit payload (pure function; no Web context, no database connection, no installation). Its fixed key order matches `PortalModuleAssemblyAuditFormatter` and the offline tool `Invoke-PortalModuleAssemblyCheck.ps1` exactly, so assembly-state and online-package artifacts corroborate each other; both use the Summary column. This class only formats and never writes.

remarks

超长时抛 `AuditSummaryTooLongException`（fail-closed），绝不静默截断导致六要素缺失。 `pkg` 使用**服务端生成的隔离暂存名**，不接受浏览器文件名、包内声明标识、来源或 capability； 一次性票据 nonce 与防伪令牌刻意不写入摘要（最小披露）。

On overflow it throws `AuditSummaryTooLongException` (fail-closed) rather than silently truncating and dropping elements. `pkg` uses the **server-generated isolated staging name** and accepts no browser file name, package-declared id, origin, or capability; the one-time ticket nonce and anti-forgery token are deliberately excluded (minimum disclosure).
