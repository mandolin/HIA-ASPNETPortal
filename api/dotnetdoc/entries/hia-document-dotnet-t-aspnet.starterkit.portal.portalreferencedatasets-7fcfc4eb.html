企业协同事项首批参考集合及未部署目录时的受限兼容值。

First collaboration-item reference sets and restricted compatibility values for an undeployed catalog.

remarks

这些值只在 `PortalBiz_ReferenceData` 尚未部署或不可读时提供回退。目录可读后，调用方必须以目录的已启用值为准，不能用该回退绕过停用。

These values are a fallback only while `PortalBiz_ReferenceData` is undeployed or unreadable. Once the catalog is readable, callers must use its active values and must not use this fallback to bypass deactivation.
