class ASPNET.StarterKit.Portal.HtmlModule

按历史兼容约定渲染受信任管理员配置的原始 HTML。 HTML 展示模块用户控件的 Designer 字段容器；字段由 ASCX 服务器控件生成。

Renders raw HTML configured by a trusted administrator under the historical compatibility convention. Designer field container for the HTML display module user control; fields are generated from ASCX server controls.

Localized Fields

remarks

这是普通模块“展示时 HTML 编码”规则的明确例外。内容必须来自受信任管理员或受控部署流程；本控件在渲染时不做净化，不适合承载普通用户输入。权限体系完善后，应由独立的“原始 HTML”能力保护此入口。

This is an explicit exception to the normal module rule of HTML-encoding at display time. Content must come from trusted administrators or a controlled deployment flow; this control does not sanitize during rendering and is not suitable for general-user input. Once the permission system is expanded, this entry should be protected by a dedicated Raw HTML capability.
