remarks

联系人模块保存的是展示资料，不是门户登录身份。调用方应在写入前完成模块编辑权限、条目归属和字段长度校验；展示层负责 HTML 编码和邮件链接生成。

The contacts module stores display information, not portal login identity. Callers should complete module-edit authorization, item ownership checks, and field-length validation before writes; the presentation layer owns HTML encoding and mail-link creation.
