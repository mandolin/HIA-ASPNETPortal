public static string ASPNET.StarterKit.Portal.PortalOnlinePackageIntegrity.SignPackage(byte[] content, string privateKeyXml)

生成 RSA-SHA256 签名，供服务端打包/发布侧使用（测试夹具也用它构造真实签名）。 私钥只由调用方持有，本方法不读取配置、不持久化密钥。

Produces an RSA-SHA256 signature for the server-side packaging/publishing path (test fixtures also use it to build real signatures). The private key is caller-held only; this method reads no config and persists no key.
