remarks

当前实现每次加载都重新绑定，保持旧模块对编辑后刷新和缓存策略的行为。数据访问层负责按模块归属和过期时间筛选； 控件层不直接拼接 SQL，也不在这里判定编辑权限。

The current implementation rebinds on every load to preserve the legacy module behavior after edits and cache decisions. The data access layer filters by module ownership and expiry time; this control does not concatenate SQL or decide edit permission here.
