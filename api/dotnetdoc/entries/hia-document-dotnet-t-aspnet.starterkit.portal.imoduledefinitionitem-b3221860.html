旧模块类型定义项契约。

Contract for a legacy module type definition item.

Localized Fields

remarks

该接口表示旧模块定义表中的一行。P3.2 后新模块来源应来自受信任部署包和模块目录， 但运行时仍需要读取旧定义以装配既有模块实例。

This interface represents one row in the legacy module-definition table. After P3.2, new module sources should come from trusted deployed packages and the module catalog, while runtime assembly still reads legacy definitions for existing module instances.
