一次待办目标解析的结果：要么给出承载业务对象的页签，要么给出降级原因码。

Outcome of one work-item target resolution: either the tab that hosts the business object, or a degradation reason code.

Localized Fields

remarks

原因码是**非敏感运维事实**（用于审计统计与排障），不含物理路径、连接串或异常细节，因此可以进入审计正文。调用方据决定呈现链接还是降级提示。

A reason code is a non-sensitive operational fact (for audit counting and diagnosis) and carries no physical path, connection string, or exception detail, so it may enter audit text. Callers useto choose between rendering a link and rendering the degraded hint.
