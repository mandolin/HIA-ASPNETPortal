remarks

该加载器服务于旧 WebForms 启动期配置扩展；调用方传入的是站点根目录下的相对路径，真实敏感值仍应优先走外置配置或环境变量覆盖。

This loader supports legacy WebForms startup-time configuration extension; callers pass a relative path under the site root, while real sensitive values should still prefer external configuration or environment-variable overrides.
