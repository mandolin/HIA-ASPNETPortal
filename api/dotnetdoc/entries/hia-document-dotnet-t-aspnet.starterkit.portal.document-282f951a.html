显示当前模块已登记文档链接的文档模块控件。 文档展示用户控件的 Designer 字段容器；字段由 ASCX 服务器控件生成。

Document-module control that displays registered document links for the current module. Designer field container for the document display user control; fields are generated from ASCX server controls.
