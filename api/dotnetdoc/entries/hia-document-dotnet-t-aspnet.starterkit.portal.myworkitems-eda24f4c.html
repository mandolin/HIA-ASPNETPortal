class ASPNET.StarterKit.Portal.MyWorkItems

前台「我的待办」聚合入口，只呈现当前用户本人或其持有角色键所指派的未完成待办。

Front-end "My To-Do Items" aggregation entry that lists only unfinished work items assigned to the current user or to role keys the user holds.

Localized Fields

remarks

本模块不办理业务、不拥有流程语义，只把既有待办投影呈现给承接人；办理必须跳转到对应业务对象。可见性、指派归属与读取结果全部由服务端判定，标记层不接受客户端提供的用户标识或状态。

This module neither processes business nor owns process semantics; it only surfaces the existing work-item projection to the assignee. Processing must navigate to the associated business object. Visibility, assignment, and read outcome are all decided server-side; the markup accepts no client-supplied user identifier or status.
