public string ASPNET.StarterKit.Portal.PortalNavigationGroupAlias.GroupDefinition.GetDisplayName(System.Globalization.CultureInfo culture)

按界面文化返回分组显示名；与 `PortalNavigationEntry.GetDisplayName` 同口径（两字母语言码判定中文）， 单侧缺失回落另一侧，两侧都缺失回落稳定键，绝不返回空标签。

Return the localized group label for a UI culture, using the same convention as `PortalNavigationEntry.GetDisplayName` (two-letter code decides Chinese); a missing side falls back to the other, and both missing fall back to the stable key, so the label is never empty.
