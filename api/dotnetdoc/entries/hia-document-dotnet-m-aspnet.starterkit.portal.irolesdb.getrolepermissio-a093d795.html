System.Collections.Generic.IEnumerable<ASPNET.StarterKit.Portal.RolePermissionEntry> ASPNET.StarterKit.Portal.IRolesDb.GetRolePermissionEntries()

读取全部角色权限映射的只读投影，用于能力权限矩阵。

Reads a read-only projection of every role-permission mapping for the capability permission matrix.

Localized Fields

remarks

本方法**只读**：不修改映射、不递增安全版本、不缓存跨请求结果。返回结果中的 `IsEnabled` 表示该映射是否生效，调用方必须把它与"未授权"区分呈现。

This method is read-only: it changes no mapping, increments no security version, and caches nothing across requests. The returned `IsEnabled` states whether a mapping is effective, and callers must render it distinctly from "not granted".

returns.summary

按角色名与权限键排序的映射集合；权限表缺失或查询失败时返回空集合。

Mappings ordered by role name and permission key; empty when the permission table is missing or the query fails.
