public static bool ASPNET.StarterKit.Portal.PortalOnlinePackageIntegrity.TryVerifySignature(byte[] content, string publicKeyXml, string signatureBase64, out string reason)

以服务端受信任公钥验证包内容的 RSA-SHA256 签名；fail-closed，任何缺失/异常/验证失败都拒绝。

Verifies the RSA-SHA256 signature of package content with a server-trusted public key; fail-closed on any absence, exception, or verification failure.

remarks

使用 4.8 已有的 `RSACryptoServiceProvider.FromXmlString` 与 `VerifyData(byte[], object, byte[])`， 哈希算法对象显式用 `SHA256.Create()`；不引入 `SignedCms` / PKCS 或 `System.Security` 新引用（避免 4.8 可用面不确定）。 签名**可选**（Q3）：是否要求签名由上层判定器决定，但一旦提供却无效，判定器也必须拒绝，避免伪造签名被忽略。

It uses `RSACryptoServiceProvider.FromXmlString` and `VerifyData(byte[], object, byte[])` already present on 4.8, with an explicit `SHA256.Create()` hash object; no `SignedCms`/PKCS or new `System.Security` reference is introduced (avoiding uncertain 4.8 API availability). Signature is **optional** (Q3): the upper gate decides whether to require it, but a supplied-yet-invalid signature must also be rejected so a forged one is never ignored.
