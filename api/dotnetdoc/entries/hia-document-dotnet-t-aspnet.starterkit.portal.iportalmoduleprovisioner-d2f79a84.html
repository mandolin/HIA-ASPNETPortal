interface ASPNET.StarterKit.Portal.IPortalModuleProvisioner

独立模块安装/卸载的可复用机制契约。安装把模块定义、页签/模块实例与包状态写入门户结构配置库，使容纳机制能实际装载运行；卸载做反向清理且不残留。

Reusable contract for installing/uninstalling independent modules. Install writes the module definition, tab/module instance and package state into the portal structural configuration so the hosting mechanism can actually load and run the module; uninstall reverses the cleanup without leaving residue.
