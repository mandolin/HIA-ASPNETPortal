class ASPNET.StarterKit.Portal.PortalOnlinePackageFailureIsolation

单模块/单上传失败隔离判定器：把「一次批量处理」拆成逐项结果， 保证某一项失败只影响该项，不扩散为整页/整批失败（backlog 容纳机制方向 #4）。

Failure-isolation evaluator for individual modules/uploads: splits a batch into per-item results so one failure affects only that item and never escalates into a whole-page/whole-batch failure (backlog accommodation direction #4).

remarks

纯逻辑、不触 IO：调用方传入每项是否已成功，本类只负责聚合与「页面是否存活」的判定。 既有通用装配层已用 `try/catch + continue`（`DesktopDefault.aspx.cs`）实现页面级隔离，本类不重复实现页面代码， 只提供可单测的判定契约。**不把失败项伪装成成功**：失败清单如实返回，页面存活仅表示「其它模块继续处理」。

Pure and IO-free: callers supply per-item success flags, and this class aggregates them and decides whether the page survived. The existing generic assembly layer already implements page-level isolation with try/catch + continue (`DesktopDefault.aspx.cs`); this class does not duplicate page code, only a unit-testable decision contract. **Failed items are never disguised as successes**: the failure list is returned honestly, and page survival only means "other modules kept processing".
