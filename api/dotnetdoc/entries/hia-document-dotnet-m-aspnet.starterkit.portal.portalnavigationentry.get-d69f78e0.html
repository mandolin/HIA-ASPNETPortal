public string ASPNET.StarterKit.Portal.PortalNavigationEntry.GetDisplayName(System.Globalization.CultureInfo culture)

按界面语言返回入口显示名：中文文化取中文名，其余文化取英文名；缺失一侧时回落到另一侧。

Return the entry display name for a UI culture: Chinese cultures use the Chinese name, other cultures use the English name, and a missing side falls back to the other.

Localized Fields

remarks

判定依据是界面文化的语言代码，与 Web.config 的 globalization uiCulture 以及 App_GlobalResources/lang.* 的解析保持同源；因此切换 uiCulture 时，管理面页头链接与页面文案会一起切换，不会出现中英混排。

The decision uses the UI culture language code and stays aligned with the Web.config globalization uiCulture and App_GlobalResources/lang.* resolution; switching uiCulture therefore switches both the admin header links and the page text together, avoiding a mixed-language surface.

params.culture.summary

目标界面文化；为 null 时使用当前线程界面文化。

Target UI culture; null uses the current thread UI culture.

returns.summary

显示名；两侧均缺失时返回稳定键，保证标签不为空。

Display name; when both sides are missing the stable key is returned so the label is never blank.
