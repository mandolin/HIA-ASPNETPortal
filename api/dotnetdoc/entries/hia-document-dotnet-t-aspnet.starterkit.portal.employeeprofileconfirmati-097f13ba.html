remarks

调用方必须先基于当前登录账号解析出门户用户标识和员工标识；本请求不承载密码、Cookie、Token 或任何身份票据内容。数据层会再次确认该用户与员工之间存在当前有效绑定，避免页面层传入过期员工标识。

Callers must resolve the Portal user id and employee id from the current sign-in context before creating this request. This request carries no password, cookie, token, or authentication-ticket content. The data layer rechecks the active user-to-employee binding so a stale employee id from the page is not trusted.
