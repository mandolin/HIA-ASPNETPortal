为已验证包创建仅指向 manifest 入口的旧定义记录。

Creates a legacy definition record pointing only to a validated manifest entry.

Localized Fields

remarks

此操作写入旧模块定义表并写入运营审计，但不复制、上传、删除或修改包目录。重复入口仅返回既有定义，不会创建第二条定义记录。

This operation writes the legacy module-definition table and an operations audit, but never copies, uploads, deletes, or modifies the package directory. A duplicate entry returns the existing definition and does not create a second definition record.
