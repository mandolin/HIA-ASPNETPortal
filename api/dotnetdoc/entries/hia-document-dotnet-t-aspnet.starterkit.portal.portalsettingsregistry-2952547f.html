remarks

registry 集中描述设置项，再由运行时解析器、数据库覆盖层和后台管理界面按其契约工作。已登记的定义是可受控读取和在线管理的唯一入口，不能以任意键绕过元数据校验；本类只提供静态策略目录，不读取实时配置、写数据库或实施页面授权。

The registry centralizes setting definitions, which are then used by the runtime resolver, database override layer, and administration UI. Registered definitions are the only controlled entry point for reads and online management, and arbitrary keys must not bypass metadata validation; this class provides a static policy catalog only and reads no live configuration, writes no database, and implements no page authorization.
