在线能力包双步确认的一次性票据：绑定账号、隔离暂存包与其哈希，并携带独立的防伪同步令牌。

One-time ticket for online capability package two-step confirmation: binds the actor, the isolated staged package and its hash, and carries an independent anti-forgery synchroniser token.

remarks

票据是不可变值对象；消费后通过 WithConsumed 返回新实例，避免共享可变状态。 **A 级硬边界**：票据只承载「谁、哪个包、什么哈希、何时、是否消费」，**不承载**包的来源声明、capability 声明或任何角色/授权结论； 这些信息永不参与授权判定。票据字段来自服务端校验结果，不接受浏览器原文作为授权依据。

The ticket is an immutable value object; consumption returns a new instance via WithConsumed so no mutable state is shared. **A-level hard boundary**: the ticket carries only "who, which package, which hash, when, whether consumed" and **never** a package origin claim, capability claim, or any role/authorization conclusion; none of those take part in authorization. Fields come from server-side validation, and raw browser text is never accepted as an authorization basis.
