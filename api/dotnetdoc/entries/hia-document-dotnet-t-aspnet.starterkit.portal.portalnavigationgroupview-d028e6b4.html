class ASPNET.StarterKit.Portal.PortalNavigationGroupView.NavigationView

一次导航渲染的完整只读视图。配置非法（`Degraded`）时调用方改为一级平铺，所有页签仍可达； 未分组页签始终平铺输出，绝不因为不属于任何词表分组而被隐藏。

Complete read-only view for one navigation render. On invalid configuration (`Degraded`) the caller falls back to flat navigation with every tab still reachable; ungrouped tabs are always rendered flat and are never hidden for lacking a vocabulary group.
