class ASPNET.StarterKit.Portal.PortalNavigationGroupView.GroupTabView

组内一个页签的展示项：保留原始 `ITabItem`（渲染层据此取本地化名与地址）、最终集合中的显示下标、 选中标记，以及入口 gate 已判定的禁用态与原因码。禁用原因码只供工具提示，不成为可见文案。

One tab's presentation item inside a group: keeps the original `ITabItem` (the renderer takes the localized name and URL from it), the display index in the final collection, the selected flag, and the disabled state and reason code already decided by the entry gate. The reason code feeds a tooltip only and never becomes visible copy.
