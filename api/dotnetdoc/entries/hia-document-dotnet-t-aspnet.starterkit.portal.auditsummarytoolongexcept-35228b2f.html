class ASPNET.StarterKit.Portal.AuditSummaryTooLongException

装配态审计摘要超过最大长度时抛出；用于阻断「静默截断导致六要素缺失」，迫使调用方改用审计表扩展方案（独立明细表）而非丢弃任何要素。

Thrown when an assembly-state audit summary exceeds the maximum length; it blocks silent truncation that would drop six-element data and forces the caller to take the audit-table extension path (a separate detail table) instead of dropping any element.

Localized Fields

remarks

定稿 §三.2 要求六要素不得静默截断：当结构化紧凑格式超过 Summary 的 500 字符上限时，抛此异常比依赖数据库截断更诚实——调用方据此知道必须走扩展表，而不是收到一条缺要素的记录。

Ruling §3.2 forbids silently truncating the six elements: when the compact format exceeds the Summary 500-character limit, throwing is more honest than relying on database truncation, because it tells the caller to take the extension-table path rather than accept a record missing elements.
