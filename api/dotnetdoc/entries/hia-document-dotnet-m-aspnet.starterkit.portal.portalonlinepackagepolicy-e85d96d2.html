public static bool ASPNET.StarterKit.Portal.PortalOnlinePackagePolicy.IsAllowedEntryName(string entryName, out string reason)

校验 ZIP 条目名是否可作为隔离目录内的相对路径，并拒绝绝对路径、父级跳转、盘符、冒号与控制字符。

Validates a ZIP entry name as a relative path inside the isolated directory, rejecting rooted paths, parent traversal, drive prefixes, colons, and control characters.

Localized Fields

remarks

本方法只做「名字本身」的策略校验；真正的路径边界断言由 PortalOnlinePackageStaging 用 Path.GetFullPath + StartsWith 完成，两者缺一不可。

This method validates the name itself; the actual destination-boundary assertion is performed by PortalOnlinePackageStaging with Path.GetFullPath + StartsWith. Both are required.

params.entryName.summary

ZIP 中央目录中的原始条目名，可为 null。

Raw entry name from the ZIP central directory; may be null.

params.reason.summary

拒绝原因的稳定短语，不回显条目名。

Stable rejection phrase that never echoes the entry name.

returns.summary

条目名可安全参与路径解析时为 true。

True when the entry name may safely take part in path resolution.
