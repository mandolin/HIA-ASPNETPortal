# 登录（Signin）

> 模块目录：`src/Portal/DesktopModules/`｜视图：`Signin.ascx`｜**无编辑页**
> 本页是**详细使用说明**；一句话速查见[用户指南的常见模块一节](../user-guide.md)。

## 用途与前置

登录模块在页签上提供**登录表单**：登录标识、口令、记住登录。它是**唯一会写运营审计**的内容路径，也**没有编辑页**——登录行为由运行期设置与认证服务决定，**不在模块实例上配置**。

前置条件：

1. **使用者侧**：进入承载登录模块的页签，输入登录标识与口令即可；阅读本页不需要任何权限。
2. **维护者侧**：本模块**没有编辑页**（不存在 `EditSignin` 之类的设置页），因此**没有"配置这个模块"的操作步骤**——能配置的是运行期设置（如是否允许自助注册）与认证服务本身。
3. **证据边界（须先知道）**：开发库中本模块是 **0 个实例**（`PortalCfg_Modules` 无 `Signin.ascx` 记录），因此**本模块没有运行期证据**；本页全部内容是**源码级说明**。再入条件：在目标环境挂载该模块实例后，可采集运行期证据并补齐实测读数。

## 操作步骤

**登录**

1. 打开承载登录模块的页签。
2. 填写**登录标识**（`EmailOrName`）与**口令**（`password`）。
3. 需要保持登录时勾选**记住登录**（`RememberCheckbox`）。
4. 点击**登录**（`SigninBtn`）提交。

**注册新账号（通常情况下不可用）**

页面上的注册入口（**`RegisterLink`**，指向 `~/Admin/Register.aspx`）**仅在 `PortalRegistrationOptions.AllowSelfRegistration` 显式开启时才可见**——**默认关闭**。也就是说：**看不到注册链接是正常状态**，不是页面出错。

**提交时口令如何被保护**

1. 提交前，页面用**一次性 RSA 公钥**把口令加密后写入隐藏字段 `EncryptedPassword`（公钥由 `~/Security/LoginPasswordKey.ashx` 提供）。
2. 服务端解密后，口令**只在当前请求内**传递。
3. 是否**强制**加密提交由 `PortalPasswordSubmissionCrypto.IsEncryptedSubmissionRequired()` 决定；未要求时才接受明文回退。

**服务端校验流程**

- 口令校验交给 `IUsersDb.SignIn`：强哈希 + **旧 MD5 兼容升级** + **多标识解析**（登录名 / 旧名 / 在职员工号 / 邮箱）。
- 成功 → `PortalAuthenticationService.SignIn` 签发**带安全版本**的票据（角色 Cookie 在认证请求阶段按需建立）。
- 失败 → 显示**通用**失败提示。

## 必填与校验

- 本模块**无编辑页**，因此**不设编辑侧的 `RequiredFieldValidator`**——上表不是"编辑页控件集"，这是与其它模块页的关键差别。
- 登录时的必填与校验发生在**认证链路**：标识与口令是否存在由表单与 `IUsersDb.SignIn` 处理，**失败提示是通用的**——**不暴露用户是否存在、审核状态或摘要比较细节**（这是有意的，避免账号枚举）。
- 口令**绝不以明文落库**：数据层负责强哈希校验与旧 MD5 兼容升级，**页面层不生成摘要**（源码注释明确）。

## 存储与审计

- **存储**：口令校验走 `UsersDB.SignIn`（`IUsersDb.SignIn`），票据由 `PortalAuthenticationService.SignIn` 签发。**登录模块本身不保存业务数据**。
- **审计（本仓唯一写运营审计的内容路径，须如实知道）**：
  - **登录失败**写一条审计：`SignInFailed`，`Outcome=Failure`，**只携带登录标识**，**绝不写口令、盐或哈希材料**；
  - **旧凭据升级**写一条：`LegacyCredentialUpgraded`；
  - **口令迭代次数升级**写一条：`CredentialCostUpgraded`。
- 与之相对：公告、联系人、讨论、文档、事件、图片、链接、快速链接、HTML 文本、XML / XSL **十个内容编辑路径都不写运营审计**。

## 权限

- **使用登录表单不需要任何权限**（它就是获取权限的入口）。
- **没有"编辑登录模块"的权限概念**：无编辑页，行为由运行期设置与认证服务决定。
- 自助注册是否可见由 `PortalRegistrationOptions.AllowSelfRegistration` 控制（默认关闭）——这是**运行期设置**，不是权限授予。

## 常见问题

**看不到注册链接**——正常：`RegisterLink` 仅在**显式开启自助注册**时才可见，默认关闭。

**登录失败提示很笼统**——有意如此：提示**不暴露用户是否存在、审核状态或摘要比较细节**，以防账号枚举。请核对标识与口令，而不是期待提示告诉你是哪一项错了。

**换了浏览器/设备后要重新登录**——未勾选"记住登录"时，会话按票据生命周期结束；勾选后按记住登录的有效期。

**用员工号能不能登录**——可以：标识解析支持登录名 / 旧名 / 在职员工号 / 邮箱。

**老账号第一次登录特别慢 / 提示升级**——旧 MD5 凭据会在校验通过时被**升级为强哈希**（`LegacyCredentialUpgraded`），这是一次性行为并会留下审计。

**想改登录框的样式或文案**——本模块**没有编辑页**，不能逐实例配置；相关调整属于运行期设置与前端资源范围。
