# HTML 文本模块（HtmlModule）

> 模块目录：`src/Portal/DesktopModules/`｜视图：`HtmlModule.ascx`｜编辑页：`EditHtml.aspx`
> 本页是**详细使用说明**；一句话速查见[用户指南的常见模块一节]({{ site.baseurl }}/user-guide/)。

## 用途与前置

HTML 文本模块在页签上渲染**一段由受信任管理员维护的原始 HTML**（欢迎语、说明块等）。它分三段内容：桌面端正文、移动端摘要、移动端详情。

前置条件：

1. 你已登录门户，并**同时**具备：
 - **模块编辑权限**（`HasEditPermissions(moduleId)`），以及
 - **更窄的「原始 HTML」权限**（`PortalPermissionKeys.ContentRawHtmlEdit`）。
2. 模块需挂载在页签上。当前部署（开发库实测）：**12 个实例**——首页 2、员工信息、产品信息、讨论区、关于门户 7，以及 `G1P2-Test-A` 测试页。
3. 编辑页的 `Mid` 来自查询串或回发的未验证集合，**必须为正整数**，否则跳转编辑拒绝页。

## 操作步骤

**写入一段 HTML 内容**

1. 打开承载 HTML 模块的页签，点击模块标题栏的编辑入口（可见性由服务器权限上下文决定）。
2. 填写**桌面端原始 HTML**（`DesktopText`）、**移动端摘要**（`MobileSummary`）、**移动端详情**（`MobileDetails`）——三者**都可留空**。
3. 保存。内容**入库前统一做 HTML 编码**，显示时再解码后原样输出（历史兼容契约）。

**清空一段内容**：把对应字段清空后保存。**记录缺失或内容为空时，视图不输出任何内容**（普通页面不暴露配置状态）。

**桌面端与移动端分别维护**：桌面端通常放完整说明，移动端放较短的摘要与详情；两者互不影响。

## 字段表

| 字段 | 控件 id | 类型 | 长度上限 | 必填 | 校验 |
| --- | --- | --- | --- | --- | --- |
| 桌面端原始 HTML | `DesktopText` | 多行文本 | 源码未设 `MaxLength` | 可选 | 无格式校验 |
| 移动端摘要 | `MobileSummary` | 多行文本 | 源码未设 `MaxLength` | 可选 | 无格式校验 |
| 移动端详情 | `MobileDetails` | 多行文本 | 源码未设 `MaxLength` | 可选 | 无格式校验 |

控件 id、类型取自 `EditHtml.aspx` 的标记，**不是本文档的估计**。

## 必填与校验

- **零必填**：该编辑页**没有任何 `RequiredFieldValidator`**，三个字段均可留空保存。
- **零格式校验**：没有比较校验、正则校验或自定义校验；三个字段**都没有长度上限**。
- 编辑页标记带 `ValidateRequest="false"`——它**仅为满足旧 Web Forms 回发兼容**，**不构成安全边界**（见下节）。
- 载入时用 `Server.HtmlDecode` 把库里的编码内容解码到编辑控件（只在受信任的编辑上下文中解码）。

## 存储与审计

- **存储**：`HtmlTextDB`——`GetHtmlText` 读取、`UpdateHtmlText` 保存；`HtmlTexts` 表按 `ModuleId` 唯一定位：**首次保存创建记录，之后只替换三个内容字段**。
- **存储约定（历史兼容契约）**：**入库前统一 HTML 编码，显示时解码**。
- **审计**：**该保存路径不写运营审计**（同族旧内容编辑页亦无），运营审计表里不会留下谁改过哪段 HTML 的记录。

## 权限

- 编辑需**同时**具备模块编辑权限与 `ContentRawHtmlEdit` 窄权限——这是本仓**唯一**要求「原始 HTML」窄权限的模块。
- 请求闸门在**每个生命周期分支之前**都重新执行（打开编辑页、取消、保存），因此无权限或非法模块号都无法通过。
- 读取与渲染不需要编辑权限。

## 常见问题

**保存后页面上出现了一段编码文本**——入库前是**编码态**存储，渲染时解码；如果内容本身含 `&`、`<`、`>` 这类字符，编辑时看到的可能是解码后的样子，保存后再看是编码后的样子。**不要把编码后的内容再复制回去**（会二次编码）。

**内容没显示**——**记录缺失或内容为空时视图不输出任何内容**（普通页面不暴露配置状态）。先确认字段里确实有内容。

**保存时被拒 / 跳到拒绝页**——多半是 `Mid` 不是正整数，或缺少 `ContentRawHtmlEdit` 权限。

**想放一段含脚本的 HTML**——**不要这样做**：本模块渲染时**不做 HTML 白名单净化**（源码：沿用"入库前编码"的历史约定，**而不是净化**），因此内容会原样进入页面。它**只能由受信任管理员维护**，**不得用于承载普通用户输入**。

**编辑框里能粘贴图片吗**——本模块只存文本，**不做文件上传**。

## 边界与不做

- 本模块**不做**内容审核、**不做**HTML 白名单净化、**不做**模板/变量替换、**不做**版本历史、**不做**发布审批、**不做**操作审计。
- **安全边界（须如实知道）**：这是"展示时 HTML 编码"规则的**明确例外**——渲染时**不做净化**，所以它**不得用于承载普通用户输入**；`ValidateRequest="false"` 只是回发兼容，**不是安全边界**。真正挡住风险的是**权限**（`ContentRawHtmlEdit` 窄权限 + 受信任管理员）。
- 本页覆盖**编辑侧的完整字段与校验**；**不依赖运行期截图**——所有结论可回溯到源码标记与已核实的部署读数。
- 部署实例数（12 个）是交付时的快照；**新增或迁移页签后需重新核对**本节。
- 与[图片]({{ site.baseurl }}/modules/image-module/)、[XML / XSL]({{ site.baseurl }}/modules/xml-module/)模块相比，本模块**有独立的业务表**（`HtmlTexts`）并**额外要求窄权限**；它是本批**唯一**渲染未净化 HTML 的模块。
