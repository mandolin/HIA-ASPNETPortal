# 第一次使用本站

> 这页解决：**第一次登录进来的人，先在哪、点什么、看到什么才算正常**。适合站点使用者与刚接触本门户的同事阅读；每个功能的具体字段与校验规则见「学习」分区的各模块页，机制与配置见「参考」分区。

## 前置条件

1. 拿到可用的登录标识与口令。登录标识可以是**登录名、旧名、在职员工号或邮箱**中的任意一种。
2. 用浏览器打开站点首页。门户在 **IE9** 及以上仍可正常使用，现代浏览器同样支持。
3. 阅读本页**不需要登录**；下面「登录后的菜单」一节需要。

## 在首页上认出三块内容

未登录时打开首页，内容区分三栏：

| 位置 | 内容 | 看什么 |
| --- | --- | --- |
| 左 | **账户登录** | 登录表单：登录标识、口令、记住登录 |
| 中 | **门户公告** | 只显示**逐条标记为游客可见**的公告；未标记的条目不会出现在这里 |
| 右 | **帮助与说明** | 站点使用说明，同时也是左侧导航里的「帮助」页 |

左侧导航在**未登录**时只有「首页」与「帮助」两项——这是正常状态：**业务功能入口只对已登录用户出现**，不登录就不会看到空壳菜单。

## 登录

1. 在首页左栏的**账户登录**卡片中填写**登录标识**与**口令**。
2. 希望保持登录状态时勾选**记住登录**。
3. 点击**登录**提交。

预期结果：顶部用户区显示你的登录名，左侧导航由两项变为六项。

> 口令在提交前由页面用**一次性 RSA 公钥**加密，服务端只在当前请求内解密，不会以明文出现在网络里。
> 口令错误时页面只给**通用失败提示**，不区分「账号不存在」与「口令不对」。

## 登录后的菜单

| 菜单项 | 用来做什么 | 谁能看见 |
| --- | --- | --- |
| 首页 | 回到登录卡与公告 | 所有人 |
| 帮助 | 站点使用说明 | 所有人 |
| 我的待办 | 汇总**未完成**的待办（只看不办） | 登录用户 |
| 请假与报销 | 请假申请与报销申请 | 登录用户 |
| 业务办理 | 提交与跟踪业务申请 | 登录用户 |
| 我的信息 | 员工资料确认与更正申请 | 登录用户 |
| 平台管理 | 站点设置、页签、模块、角色与用户 | 仅管理员 |
| 企业能力工作台 | 协作条目的提交、重新提交与评论 | 仅管理员 |

> 菜单文字随界面语言变化：中文界面显示「我的待办」，英文界面显示「My To-Do Items」。上表为中文界面写法。

## 查看我的待办

1. 在左侧导航点击**我的待办**。
2. 页面加载即列出**指派给你、或你持有的角色键所指派**的**未完成**待办——无需点任何按钮。
3. 只看逾期项时点击**逾期**；要回到全量时点击**全部**。

预期结果：列表里每条待办都标明它的**来源模块**。

> **待办在这里只能看、不能办**：本模块**只呈现、不办理**——不审批、不改数据、不回写来源模块。办理要回到产生该待办的模块（例如费用报销、请假申请、业务申请）里完成。

## 回到来源模块办理

1. 在待办列表里找到那条待办，记下它标出的来源。
2. 在左侧导航点击对应的页签（例如「请假与报销」）。
3. 在该页签内完成申请或处理动作。

预期结果：处理完成后，该待办从「我的待办」中消失——因为本模块只列未完成项。

## 看不到东西时怎么排查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 左侧只有「首页」和「帮助」 | 尚未登录（业务入口对未登录访客隐藏） | 先登录 |
| 登录后仍看不到「我的待办」等入口 | 登录未成功；或该入口对当前账号不可见 | 确认顶部是否显示登录名；必要时请管理员确认账号是否已开通 |
| 「我的待办」列表是空的 | 当前没有与你相关的未完成事项 | 正常状态；本模块只列未完成项 |
| 某条待办不见了 | 它已完成、被指派给了别人，或其来源模块不在聚合范围内 | 到来源模块确认 |
| 「我的待办」里找不到可点的办理按钮 | 本模块不提供就地办理 | 回来源模块办理 |
| 首页公告区是空的 | 公告需**逐条**标记为游客可见才会出现在这里 | 联系站点管理员 |
