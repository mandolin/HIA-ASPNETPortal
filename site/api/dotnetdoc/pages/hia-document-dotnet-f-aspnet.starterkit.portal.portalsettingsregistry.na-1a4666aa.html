NavigationGroupAliases

dotnet-field.NET
public static readonly ASPNET.StarterKit.Portal.PortalSettingDefinition ASPNET.StarterKit.Portal.PortalSettingsRegistry.NavigationGroupAliases

主导航分组配置别名覆盖；默认空表示采用 `PortalNavigationGroupAlias` 封闭词表的默认分组。 非法配置由解析层 fail-closed 回退，绝不隐藏页签；该设置只影响展示层级，不作为授权依据。

Main-navigation group configuration alias override; an empty default adopts the closed vocabulary defaults in `PortalNavigationGroupAlias`. Invalid configuration fails closed in the parser and never hides a tab; this setting affects presentation hierarchy only and is never an authorization basis.
