TryValidateSnapshot

dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalOnlinePackageRollbackDrill.TryValidateSnapshot(ASPNET.StarterKit.Portal.PortalOnlinePackageSnapshot snapshot, out string reason)

校验一份快照是否可作为还原依据：条目非空、路径合法、长度非负、摘要为 64 位 hex， 且相对路径不重复（防同一文件被两条记录覆盖）。

Validates a snapshot as a restore basis: entries present, paths legal, lengths non-negative, digests 64-char hex, and relative paths unique (so one file cannot be covered by two records).
