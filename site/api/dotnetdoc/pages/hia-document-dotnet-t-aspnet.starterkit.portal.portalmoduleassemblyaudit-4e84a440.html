PortalModuleAssemblyAudit

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalModuleAssemblyAudit

模块装配态审计的运行时写入包装（承载于 Web 项目，依赖 PortalOperationAudit）。summary 应为 PortalModuleAssemblyAuditFormatter 的产物（已确保 ≤500 且不截断）。本类不读取台账、不改变装配态、不触发编译。

Runtime write wrapper for module assembly-state audits (lives in the Web project, depends on PortalOperationAudit). summary should be the output of PortalModuleAssemblyAuditFormatter (already guaranteed ≤500 and non-truncated). This class reads no ledger, changes no assembly mode, and triggers no compilation.

Localized Fields

remarks

写入经由 PortalOperationAudit.Record，本身为 best-effort（失败只记诊断、不冒泡）。审计只用于追溯，装配态的唯一事实源仍是台账（定稿 §二）。 与离线工具 Invoke-PortalModuleAssemblyCheck.ps1 的关系：工具生成可审阅 SQL 产物而不连库；本包装是「审批通过后由运行时记录」的同等能力入口。

Writes go through PortalOperationAudit.Record, which is best-effort (failures only log diagnostics, never bubble). Audit is only for traceability; the ledger remains the single source of truth for assembly mode (ruling §2). Relationship with the offline tool Invoke-PortalModuleAssemblyCheck.ps1: the tool generates a reviewable SQL artifact without connecting to a database; this wrapper is the equivalent runtime entry point for "record after approval".
