IPortalModuleControl

dotnet-type.NET
interface ASPNET.StarterKit.Portal.IPortalModuleControl

定义门户动态加载器在桌面模块加入控件树前必须绑定的运行时上下文契约。

Defines the runtime-context contract that the portal dynamic loader must bind before a desktop module joins the control tree.

Localized Fields

remarks

实现此接口只是通过动态加载器接口门禁的必要条件，不证明入口、包、Tab、Portal 或用户权限。加载器负责提供与；模块仍须在每个读写动作处实施服务器端授权、输入验证和输出编码。

Implementing this interface is only a prerequisite for passing the dynamic loader's interface gate; it proves neither entry/package trust nor Tab, Portal, or user authorization. The loader suppliesand, while the module must still enforce server-side authorization, input validation, and output encoding at each read or write action.
