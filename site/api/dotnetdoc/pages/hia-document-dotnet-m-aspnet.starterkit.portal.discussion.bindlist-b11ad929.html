private void ASPNET.StarterKit.Portal.Discussion.BindList()

把当前模块的顶级讨论主题绑定到外层列表。

Binds the current module's top-level discussion topics to the outer list.

Localized Fields

remarks

列表会在展开/折叠命令后重绑，避免让模板直接承担状态转换逻辑；回复数据仍由选中项的数据绑定阶段按需读取。

The list is rebound after expand/collapse commands so the template does not own state transitions; reply data is still loaded on demand during selected-item binding.
