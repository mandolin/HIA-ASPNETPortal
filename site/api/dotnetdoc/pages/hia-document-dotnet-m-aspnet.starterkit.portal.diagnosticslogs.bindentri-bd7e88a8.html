按当前日期和文本筛选条件查询并绑定诊断事件。

Queries and binds diagnostics events using the current date and text filters.

Localized Fields

remarks

日期解析失败时清空旧结果；成功后将页码、固定页大小和筛选值交给只读查询服务，并只显示服务返回的截断提示。

Invalid dates clear stale results; valid dates pass the page, fixed page size, and filter values to the read-only query service and display only its truncation notice.
