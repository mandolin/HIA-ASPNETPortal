Localized Fields

remarks

生命周期保持既有顺序：先在选择唯一原生 Theme，再注入当前请求依赖， 最后调用。该顺序直接影响 Web Forms 主题资源加载和页面控件树构建， 不能因为派生页 UI 需要或文档化整理而随意重排。

The lifecycle keeps the existing order:selects the single native Theme first, injects current-request dependencies next, and finally calls. This order directly affects Web Forms theme resource loading and page control-tree construction, so derived-page UI needs or documentation cleanup must not casually reorder it.
