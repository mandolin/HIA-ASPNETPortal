IsModuleActionPermissionWellFormed

dotnet-method.NET
public static ASPNET.StarterKit.Portal.PortalModulePermissionAuditContract.Decision ASPNET.StarterKit.Portal.PortalModulePermissionAuditContract.IsModuleActionPermissionWellFormed(string permissionKey, System.Collections.Generic.IList<string> registeredKeys)

判定形态相关动作权限键：须在调用方传入的已登记权限键集合内（fail-closed）， 不得为管理级前缀（`Admins` / `Admin` / `Business.Admin`，与 `PortalModuleProvisioner.IsAdminCapability` 同口径）， 不得为扁平单层键（`EnterpriseCapability.Manage`，与 `PortalPermissions.cs:538-539` 注释一致）。 本判定不新增权限键常量，也不改变 `EnterpriseCapability.*` 七键的既有分层。

Decides whether a form-related action permission key is well formed: it must be in the caller-supplied registered-key set (fail closed), must not use an administrative prefix (same rule as `PortalModuleProvisioner.IsAdminCapability`), and must not be a flat single-layer key (per the note at `PortalPermissions.cs:538-539`). No new key constant is added and the existing seven-layer `EnterpriseCapability.*` shape is unchanged.
