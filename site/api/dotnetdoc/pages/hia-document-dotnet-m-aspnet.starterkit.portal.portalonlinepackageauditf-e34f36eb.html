FormatSixElementSummary

dotnet-method.NET
public static string ASPNET.StarterKit.Portal.PortalOnlinePackageAuditFormatter.FormatSixElementSummary(string stagingName, string hashBefore, string hashAfter, string actor, System.DateTime startUtc, System.DateTime endUtc, string verification, string direction)

六要素紧凑格式：固定键序、分号分隔、时间用秒级 ISO 8601 UTC；超过 MaxSummaryLength 时抛出，绝不静默截断。字段顺序与装配态格式器逐字一致。 AuditSummaryTooLongException

Six-element compact format: fixed key order, semicolon separated, second-precision ISO 8601 UTC; when exceeding MaxSummaryLength it throws `AuditSummaryTooLongException` instead of silently truncating. Field order is character-for-character identical to the assembly-state formatter.
