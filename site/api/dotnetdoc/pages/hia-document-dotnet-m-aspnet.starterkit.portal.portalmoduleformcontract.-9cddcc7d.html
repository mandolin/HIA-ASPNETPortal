public static bool ASPNET.StarterKit.Portal.PortalModuleFormContract.TryValidate(ASPNET.StarterKit.Portal.PortalModuleFormContract.FieldInput hostFramework, ASPNET.StarterKit.Portal.PortalModuleFormContract.FieldInput entryKind, System.Collections.Generic.IList<string> dependencies, out System.Collections.Generic.IList<string> reasons)

只读校验形态字段。返回 false 时 reasons 至少含一条受控原因；返回 true 时 reasons 为空。 不修改任何输入、不读文件/配置。调用方须先把 JSON 字段映射为 FieldInput / 字符串集合。

Read-only validation of form fields. On false, reasons contains at least one controlled reason; on true it is empty. No input is mutated and no file/config is read. Callers must map JSON fields to FieldInput / string collections first.
