ASPNET.StarterKit.Portal.IHtmlTextItem

受信任 HTML 模块内容项契约。

Contract for a trusted HTML module content item.

Localized Fields

remarks

该接口服务于旧 HTML 模块编辑与展示路径。`DesktopHtml` 可以包含受信任管理员保存的原始 HTML； 允许输入原始 HTML 的权限、请求验证例外和未来净化策略必须在页面/权限层显式处理。

This interface serves the legacy HTML module editing and display paths. `DesktopHtml` may contain raw HTML saved by trusted administrators; permission to enter raw HTML, request-validation exceptions, and future sanitization policy must be handled explicitly in the page or authorization layer.
