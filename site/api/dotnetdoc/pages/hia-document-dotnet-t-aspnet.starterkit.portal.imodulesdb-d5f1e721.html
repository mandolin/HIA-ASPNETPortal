remarks

本契约区分可缺失的外部标识查找与严格配置读取。页面授权或请求验证可使用；已验证的运行时装配、更新和删除使用严格方法，以便暴露配置或关系完整性问题。

This contract distinguishes nullable external-identifier lookup from strict configuration reads. Page authorization or request validation may use; verified runtime assembly, updates, and deletes use strict methods so configuration or relationship-integrity issues remain visible.
