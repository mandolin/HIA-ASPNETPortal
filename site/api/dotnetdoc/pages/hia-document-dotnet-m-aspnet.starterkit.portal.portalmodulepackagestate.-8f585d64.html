ASPNET.StarterKit.Portal.PortalModulePackageState(string, bool, bool, System.DateTime, string, string)

创建一个模块包运行状态快照。

Creates a runtime state snapshot for a module package.

Localized Fields

params.packageId.summary

与该快照关联的稳定包标识；空值归一为稳定空文本，不在此重新验证部署。

Stable package identifier associated with this snapshot; null is normalized to stable empty text and deployment is not revalidated here.

params.isEnabled.summary

状态表返回的显式启停值，或缺行时的兼容默认值；它不越过其它模块门禁。

Explicit enabled value returned by the state table, or the compatibility default for a missing row; it does not bypass other module gates.

params.isConfigured.summary

是否已有显式状态行；false 与不可用状态表不同，后者不创建本快照。

Whether an explicit state row exists; false differs from an unavailable table, which does not create this snapshot.

params.updatedUtc.summary

显式行的最近 UTC 时间；默认快照使用既有哨兵值。

Latest UTC time from an explicit row; the default snapshot uses the existing sentinel value.

params.updatedBy.summary

显式行的操作人文本；空值归一为稳定空文本。

Actor text from an explicit row; null is normalized to stable empty text.

params.note.summary

显式行的可选备注文本；空值归一为稳定空文本。

Optional note text from an explicit row; null is normalized to stable empty text.
