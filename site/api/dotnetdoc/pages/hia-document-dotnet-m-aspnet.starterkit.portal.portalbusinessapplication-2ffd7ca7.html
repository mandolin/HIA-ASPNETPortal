BuildSqlStatusPredicate

dotnet-method.NET
public static string ASPNET.StarterKit.Portal.PortalBusinessApplicationTransitions.BuildSqlStatusPredicate()

由迁移表生成后台审核 SQL 的状态谓词（仅含走审核路径的动作），使写入守卫与迁移表同源、消除漂移。

Generates the administration review SQL status predicate from the transition table (review-path actions only), keeping the write guard and the table from one source and eliminating drift.

Localized Fields

remarks

谓词逐条比较并要求当前状态落在该动作的合法来源集合内；因为四个审核动作的来源集合相同，生成结果与显式化之前的手写窗口**语义等价**（有单测守护）。返回文本只由受控常量拼成，不接受调用方输入。 @ActionKey

Each clause comparesand requires the current status to fall inside the action's legal source set. Because the four review actions share the same source set, the generated text is semantically equivalent to the hand-written window it replaces (guarded by a unit test). The returned text is composed only from controlled constants and never from caller input. @ActionKey
