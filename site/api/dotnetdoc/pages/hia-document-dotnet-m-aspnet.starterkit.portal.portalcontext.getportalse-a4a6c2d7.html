GetPortalSettings

dotnet-method.NET
ASPNET.StarterKit.Portal.PortalContext.GetPortalSettings(System.Web.HttpContext) /* return type unavailable */

读取当前请求的门户上下文；缺失时抛出明确异常，便于定位早期空引用问题。

Reads the current request's portal context and throws a clear exception when it is missing to expose early lifecycle defects.
