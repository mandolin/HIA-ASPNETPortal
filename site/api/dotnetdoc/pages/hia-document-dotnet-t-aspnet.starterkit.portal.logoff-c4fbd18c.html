处理门户用户注销的页面。 注销页的 Designer partial 容器；ASPX 不声明服务器控件，因此当前没有生成字段。

Page that handles portal user sign-out. Designer partial container for the logoff page; the ASPX declares no server controls, so no generated fields are present.

注销逻辑通过统一认证服务清理主认证 Cookie 和角色 Cookie，避免虚拟目录 Path 不一致导致旧 Cookie 残留。

Sign-out uses the shared authentication service to clear both the main auth cookie and the role cookie, preventing stale cookies caused by virtual-directory path differences.
