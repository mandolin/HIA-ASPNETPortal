按表名与列名探测列是否存在，用于 P47.1 父项列等**部署级迁移**的兼容判断： 迁移未执行时列可能不存在，读取前先探测，据此选择真实列投影或 NULL 投影，避免旧库上读取失败。 与同样，表名只允许来自编译期常量；列名则通过参数化传入，不参与 SQL 文本拼接。

Probes whether a column exists, used for deployment-level migrations such as the P47.1 parent column: the column may be absent before the migration runs, so it is probed before reads to choose either the real column projection or a NULL projection, avoiding read failures on older databases. As with, the table name may only come from a compile-time constant; the column name is passed through aand never participates in SQL text concatenation.
