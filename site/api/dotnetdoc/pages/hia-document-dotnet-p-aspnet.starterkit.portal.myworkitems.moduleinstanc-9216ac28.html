ModuleInstancesConfig

dotnet-property.NET
public IModulesDb ASPNET.StarterKit.Portal.MyWorkItems.ModuleInstancesConfig { private get; set; }

模块实例数据访问门面，用于按模块定义标识枚举实例并读回其承载页签。基类已注入同类型的私有副本（其 getter 为 private，派生类与嵌套类型都读不到），故此处保留本模块可读的注入点；两处注入的是同一容器注册的同一实现，不产生第二套数据源。

Module-instance data-access facade used to enumerate instances by definition identifier and read back their hosting tab. The base class already injects a private copy of the same type whose getter is private, so neither derived nor nested types can read it; this keeps an injection point this module can read. Both injections resolve the same container registration, so no second data source appears.
