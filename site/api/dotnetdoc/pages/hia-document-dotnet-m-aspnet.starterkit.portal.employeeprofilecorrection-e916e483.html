处理请求列表中的管理员状态命令。

Handles administrator status commands from the request list.

Localized Fields

remarks

命令状态先经过固定白名单和按状态分支的权限检查，再解析正数请求标识并调用数据服务。审核事实成功后才记录运营审计；待办同步是后续旁路，不能被文档化为与审核写入同一事务。

The command status passes a fixed allowlist and status-specific permission check before the positive request identifier is parsed and the data service is called. Operations audit is recorded only after the review fact succeeds; work-item synchronization is a later sidecar and must not be documented as the same transaction as the review write.
