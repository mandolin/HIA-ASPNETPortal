ASPNET.StarterKit.Portal.PortalRegistrationInviteRejection

临时注册链接邀请码的校验拒绝原因。数据层只返回该原因码，面向用户的文案由表现层按当前语言映射，使本地化文本不进入数据层。

Rejection reason for validating a temporary registration invite code. The data layer returns only this code, and the presentation layer maps it to user-facing text for the current language, keeping localized strings out of the data layer.
