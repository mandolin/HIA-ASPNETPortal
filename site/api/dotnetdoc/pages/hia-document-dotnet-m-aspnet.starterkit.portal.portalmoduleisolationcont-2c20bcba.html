public static ASPNET.StarterKit.Portal.PortalModuleIsolationContract.Decision ASPNET.StarterKit.Portal.PortalModuleIsolationContract.IsEntryUnique(System.Collections.Generic.IList<ASPNET.StarterKit.Portal.PortalNavigationEntry> entries, string entryKey)

判定入口键在单一真源中是否恰好命中一次。`entries` 由调用方从 `PortalNavigationRegistry.GetEntries()` 取得；空白键或不唯一即判不成立。

Decides whether an entry key hits the single source exactly once. `entries` comes from `PortalNavigationRegistry.GetEntries()`; a blank key or a duplicate does not hold.
