BusinessId

dotnet-property.NET
public string ASPNET.StarterKit.Portal.PortalWorkItemCompletionRequest.BusinessId { get; set; }

必填业务对象标识；以字符串保存并由当前数据层裁剪至 80 个字符，便于不同业务对象共用同一待办表。标识本身不证明对象存在或调用方可访问。

Required business-object identifier stored as text and trimmed to 80 characters by the current data layer so different business objects can share one work-item table. The identifier itself proves neither object existence nor caller access.
