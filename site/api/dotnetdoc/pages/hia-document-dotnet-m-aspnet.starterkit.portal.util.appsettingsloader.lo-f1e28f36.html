把 JSON 中的 appSettings 键值写入 `ConfigurationManager.AppSettings`。

Writes JSON appSettings key/value pairs into `ConfigurationManager.AppSettings`.

Localized Fields

remarks

该方法只处理普通 appSettings 字符串值，不负责连接串、密钥加密或复杂对象绑定。

This method handles only ordinary appSettings string values and does not manage connection strings, secret encryption, or complex object binding.

params.appSettings.summary

JSON `appSettings` 对象；为空时不做任何修改。

JSON `appSettings` object; when null, no changes are applied.

params.preservePrevious.summary

是否保留 JSON 中未声明的既有键；为 false 时会移除未声明键。

Whether to keep existing keys not declared by JSON; when false, undeclared keys are removed.
