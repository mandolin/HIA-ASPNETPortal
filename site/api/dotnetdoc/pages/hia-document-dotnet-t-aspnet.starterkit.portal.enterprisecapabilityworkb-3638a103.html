remarks

P22.4 首版只复用 P21 企业协同事项、待办和运营审计链路，提供普通用户提交与本人查看入口。 它不引入动态表单、附件、在线脚本或领域专有字段，以便先验证 Profile gate 下的最小前后台闭环。

The first P22.4 version reuses the P21 collaboration-item, work-item, and operation-audit loop only, giving ordinary users a submit-and-own-list entry. It does not introduce dynamic forms, attachments, online scripts, or domain-specific fields, so the first proof can focus on the minimum front/back loop under the Profile gate.
