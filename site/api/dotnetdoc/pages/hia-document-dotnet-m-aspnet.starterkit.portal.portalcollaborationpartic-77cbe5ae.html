public static System.Collections.Generic.IList<string> ASPNET.StarterKit.Portal.PortalCollaborationParticipantText.BuildParticipantLines(System.Collections.Generic.IList<ASPNET.StarterKit.Portal.CollaborationItemParticipantInfo> participants)

把参与人集合渲染为**逐人一行**的展示序列；空集合返回仅含占位文本的单元素序列。

Renders the participant set as **one line per person**; an empty set returns a single placeholder line.

Localized Fields

remarks

与**共用同一条格式串**， 因此"逗号连接"与"逐人一行"两种呈现不会出现本地化排版的漂移 —— 这正是引入共享渲染器要防的问题。 本方法是**新增**而非替换：逗号串仍被前台与后台的两处只读展示使用，逐行呈现按需选用，互不影响。 Collaboration_ParticipantDisplayFormat P74.4

This method **shares the same format string**with, so the "comma-joined" and "one line per person" renderings cannot drift apart in localized typography — exactly what the shared renderer introduced in P74.4 was meant to prevent. It is **added rather than replacing**: the comma-joined text is still used by the two read-only displays in the front office and the admin area, while the per-line rendering is opted into where needed.
