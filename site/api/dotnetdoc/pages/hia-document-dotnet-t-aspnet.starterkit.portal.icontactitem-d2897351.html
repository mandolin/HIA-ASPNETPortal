interface ASPNET.StarterKit.Portal.IContactItem

联系人模块条目的跨层只读/可写契约。

Cross-layer readable/writable contract for a contact module item.

Localized Fields

remarks

该接口用于旧联系人数据访问和展示控件之间传递展示型资料。邮箱和联系方式不代表登录身份； 展示层必须负责 HTML 编码和邮件链接安全处理。

This interface passes display-oriented contact data between legacy contact data access and display controls. Email and contact fields do not represent login identity; presentation code must perform HTML encoding and safe mail-link handling.
