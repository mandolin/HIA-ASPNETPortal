规范化权限键集合，并拒绝未定义键名。

Normalizes a permission-key collection and rejects undefined keys.

remarks

空集合输入返回空数组；非空但未定义的键会沿用单键方法抛出异常；结果按不区分大小写去重并排序。

A null collection returns an empty array; a non-blank undefined key propagates the single-key method's exception; results are deduplicated and sorted case-insensitively.
