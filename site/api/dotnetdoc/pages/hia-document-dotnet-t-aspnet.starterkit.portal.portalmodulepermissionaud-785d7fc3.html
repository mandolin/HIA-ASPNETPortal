PortalModulePermissionAuditContract

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalModulePermissionAuditContract

权限与审计的**纯内存只读契约判定器**：把形态相关「安装 / 启用 / 停用」权限键、 运营审计事件词表与 A 级三条硬边界收敛为可机器核对的判定。词表全部由调用方传入 （`PortalPermissionRegistry` / `PortalCapabilityRegistry` / 审计词表在各自项目维护）， 本类不引用 Web 项目的 `PortalOperationAuditEvents`、不读配置、不写任何内容、 **不新增权限键常量或审计事件常量**（避免与单一事实源漂移）。

Pure in-memory read-only contract decisions for permission and audit: machine-checkable rules for form-related install/enable/disable permission keys, the operations-audit vocabulary, and the three A-level hard boundaries. All vocabularies are supplied by callers (registries live in their own projects); this class does not reference the Web project's `PortalOperationAuditEvents`, reads no config, writes nothing, and adds **no new permission-key or audit-event constants** (avoiding drift from the single source of truth).
