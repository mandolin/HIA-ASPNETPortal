Events

dotnet-type.NET
ASPNET.StarterKit.Portal.Events

显示当前模块的事件列表。 事件展示用户控件的 Designer 字段容器；字段由 ASCX 服务器控件生成。

Renders the event list for the current module. Designer field container for the events display user control; fields are generated from ASCX server controls.

Localized Fields

remarks

该控件沿用旧 Web Forms 数据绑定模型：从事件数据访问服务读取当前模块未过期事件，再交给标记层展示。事件标题、地点时间、描述和 URL 的最终输出仍依赖标记层编码与导航策略。 DataList

This control keeps the legacy Web Forms data-binding model: it reads non-expired events for the current module from the event data access service and passes them to the markup. Final output of event title, time/place text, description, and URL still depends on markup encoding and navigation policy. DataList
