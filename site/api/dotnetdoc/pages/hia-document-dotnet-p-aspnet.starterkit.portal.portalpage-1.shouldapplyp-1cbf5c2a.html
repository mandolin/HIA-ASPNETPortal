指示当前页面是否应加载门户 Web Forms 主题。

Indicates whether the current page should load the Portal Web Forms theme.

Localized Fields

remarks

普通页面应保持默认值；仅无 HTML 外壳的下载、流式响应或极少数兼容页面可覆写为， 以避免 Web Forms 在没有的页面上强制注入主题样式。 false <head runat="server" />

Normal pages should keep the default value. Only download, streaming-response, or rare compatibility pages without an HTML shell should override this to, avoiding Web Forms stylesheet injection on pages that do not have. false <head runat="server" />
