TryEvaluateScenario

dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalOnlinePackageRollbackDrill.TryEvaluateScenario(ASPNET.StarterKit.Portal.PortalOnlinePackageRollbackScenario scenario, out string verdict, out string reason)

按三种演练情形判定「是否允许继续安装」，并给出稳定的结论短语。 三种情形全部返回「拒绝继续」，但各自保留独立原因，便于证据区分「为什么没继续」。

Decides whether installation may continue for each of the three drill scenarios and returns stable verdict phrases. All three refuse to continue, each with a distinct reason so evidence distinguishes "why it stopped".
