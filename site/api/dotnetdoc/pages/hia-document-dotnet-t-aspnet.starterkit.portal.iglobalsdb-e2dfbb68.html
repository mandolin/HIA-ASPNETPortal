dotnet-type.NET
ASPNET.StarterKit.Portal.IGlobalsDb

旧门户全局配置的数据访问契约。

Data access contract for legacy portal global configuration.

Localized Fields

remarks

该契约只覆盖旧全局配置表中的门户名称和编辑按钮策略。系统设置、主题设置、审计和权限判断 已在后来的配置体系中分层处理，不应混入这里。

This contract only covers the portal name and edit-button policy stored in the legacy global configuration table. System settings, theme settings, auditing, and authorization checks are layered elsewhere and should not be mixed into this contract.
