Contract for checking Portal module-edit permissions.

remarks

该契约用于旧内容模块编辑入口的最后一道门禁。它不替代页面层的请求参数解析、条目归属检查或业务级权限判断。

This contract is the final gate for legacy content-module edit entries. It does not replace page-layer request parsing, item ownership checks, or business-level authorization.
