TryParseAliases

dotnet-method.NET
public static bool ASPNET.StarterKit.Portal.PortalNavigationGroupAlias.TryParseAliases(string configuration, out System.Collections.Generic.IDictionary<string, string> aliases, out string reason)

解析部署侧 `Portal.Navigation.GroupAliases` 覆盖文本，产出「页签键 → 分组键」的别名映射。 仅接受词表内的分组键与 `NavigationKey=GroupKey` 形态；重复页签键或未知分组键一律判为非法， **整份配置 fail-closed 拒绝**（不采用部分覆盖），调用方据此回退默认词表并保持页签全部可达。

Parse the deployment `Portal.Navigation.GroupAliases` override text into a tab-key to group-key alias map. Only vocabulary group keys and `NavigationKey=GroupKey` pairs are accepted; duplicate tab keys or unknown group keys make the **entire configuration fail closed** (no partial override is adopted), so the caller falls back to defaults and keeps every tab reachable.
