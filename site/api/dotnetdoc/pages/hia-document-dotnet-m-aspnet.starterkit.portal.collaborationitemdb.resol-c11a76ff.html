ResolveVisibleOrganizationUnitIds

dotnet-method.NET
ASPNET.StarterKit.Portal.CollaborationItemDb.ResolveVisibleOrganizationUnitIds(int) /* return type unavailable */

解析当前动作人可见的组织单元范围；范围未知时返回空集合，使组织维度不授予可见性。

Resolves the organization-unit scope visible to the current actor; returns an empty collection when the scope is unknown so the organization dimension grants no visibility.

Localized Fields

remarks

组织范围来自账号与员工的有效绑定及员工主数据；缺目录服务、缺绑定、缺员工号或读取异常一律返回空集合，绝不因组织维度解析失败而放宽可见性。

The organization scope comes from the active user-to-employee binding and employee master data; a missing directory service, missing binding, missing employee code, or read failure all return an empty collection, and the organization dimension is never widened by a resolution failure.

params.actorUserId.summary

服务端重新解析得到的门户用户标识；非正值直接返回空集合。

Portal-user identifier re-resolved by the server; a non-positive value returns an empty collection directly.

returns.summary

可见组织单元标识集合；当前只解析动作人所属组织单元本身，子树展开留作后续深化项。

Visible organization-unit identifiers; currently only the actor's own organization unit is resolved, while subtree expansion remains a later deepening item.
