数据库状态动作批次返回的最小事项写入结果。

Minimal item-write result returned by the database state-action batch.

Localized Fields

remarks

该类型只承载批次明确返回的标识和编码，供调用方区分实际更新与零行并发失败；它不是新的授权来源，也不包含数据库异常详情。

This type carries only the identifier and code explicitly returned by the batch so callers can distinguish an actual update from a zero-row concurrency failure; it is not an authorization source and contains no database exception detail.
