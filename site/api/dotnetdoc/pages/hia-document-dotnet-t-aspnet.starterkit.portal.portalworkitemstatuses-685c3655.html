Work-item status describes task handling only and does not replace the business object's domain status. These strings are persisted to the database, audit records, and documentation, so they must not be casually renamed. This class defines neither legal transitions, terminal states, expiration calculation, nor authorization rules; callers must enforce those decisions at the domain boundary.
