public int ASPNET.StarterKit.Portal.CachedPortalModuleControl.ModuleId { get; }

从已绑定模块配置获取模块实例标识。

Gets the module-instance identifier from the bound module configuration.

Localized Fields

remarks

该值直接投影，既不生成新标识，也不证明模块属于当前 Portal 或当前用户已获授权。

The value directly projects; it neither creates a new identifier nor proves that the module belongs to the current Portal or is authorized for the current user.

exceptions.T:System.NullReferenceException.summary

尚未绑定 ModuleConfiguration 时访问该属性。

The property is accessed before ModuleConfiguration is bound.
