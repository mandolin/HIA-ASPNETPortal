Probes whether a database object exists by table name, used to decide before reads or writes whether a migration has already run. The table name is interpolated into the SQL string — the only place in this class where an identifier is not parameterized — so the **safety invariant** must hold: callers may pass only compile-time constants (this class's/, or literal table names within this file), never an identifier from a page, query string, or any other external input. Ordinary static checks cannot prove that constraint, so it is registered here explicitly.
