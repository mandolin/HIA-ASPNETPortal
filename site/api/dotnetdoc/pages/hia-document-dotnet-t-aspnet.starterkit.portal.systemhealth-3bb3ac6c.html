只读系统健康状态页面。

Read-only system health page.

Localized Fields

remarks

页面只执行受控健康检查并展示快照，不写入数据库、配置或运行状态；刷新动作仍受同一运维查看权限保护。

The page runs only the controlled health check and displays its snapshot; it does not write databases, configuration, or runtime state, and refresh remains protected by the same operations-view permission.
