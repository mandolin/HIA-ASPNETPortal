remarks

P12.3 第一版只负责业务对象到待办记录的最小投影，不实现 BPM、转办、会签或外部通知。该门面不校验业务对象权限，也不与调用方的业务事务形成原子边界；调用方必须先完成授权和领域写入，并把待办失败作为补充能力降级处理。

The first P12.3 version only projects business objects into minimal work-item records; it does not implement BPM, delegation, co-signing, or external notifications. This facade validates neither business-object authorization nor an atomic boundary with the caller's domain transaction. Callers must authorize and persist the domain action first, then treat work-item failures as degradation of supplemental capability.
