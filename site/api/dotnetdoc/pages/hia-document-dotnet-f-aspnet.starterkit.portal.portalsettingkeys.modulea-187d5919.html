ModuleAssemblyAllowCodeFile

dotnet-field.NET
public const string ASPNET.StarterKit.Portal.PortalSettingKeys.ModuleAssemblyAllowCodeFile

是否允许装配态台账中出现受控调试态（CodeFile）的部署级开关键；缺省关闭，且不允许在线编辑或数据库覆盖。

Deployment-level switch key controlling whether the assembly-state ledger may contain the controlled debug mode (CodeFile); disabled by default, with neither online editing nor database override permitted.

Localized Fields

remarks

本键只表达"环境是否允许"，不表达任何模块当前处于何种装配态；装配态的唯一事实源是 Config/module-assembly-state.json 台账。

This key expresses only "whether the environment allows it", never the current mode of any module; the ledger at Config/module-assembly-state.json is the single source of truth for assembly mode.
