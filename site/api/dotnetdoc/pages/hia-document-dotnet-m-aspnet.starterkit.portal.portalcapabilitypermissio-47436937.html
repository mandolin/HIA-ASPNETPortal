ASPNET.StarterKit.Portal.PortalCapabilityPermissionMatrixRenderer.IsCategoryLayerRegistered(string) /* return type unavailable */

判断权限分类是否已在受控映射中登记层归属。

Determines whether a permission category already declares its capability layer in the controlled mapping.

Localized Fields

remarks

本方法供契约测试使用：它区分"显式登记"与"落入默认层"两种情形，使"新增权限分类忘记登记层归属"能被测试当场发现，而不是被默认值静默掩盖。

This method exists for the contract test: it distinguishes an explicit registration from a fallback to the default layer, so a newly added category that forgets to declare its layer is caught by the test instead of being silently masked by the default.
