remarks

该上下文仍映射旧 Portal 用户/角色表，同时承载新增凭据、安全版本和企业用户资料扩展表。新表尽量不建立导航关系，避免扩大旧实体跟踪范围。

This context still maps the legacy Portal user and role tables while carrying new credential, security-version and enterprise profile extension tables. New tables intentionally avoid navigation properties where possible so legacy entity tracking stays narrow.
