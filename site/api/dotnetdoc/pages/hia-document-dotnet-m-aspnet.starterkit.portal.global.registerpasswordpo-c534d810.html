RegisterPasswordPolicyOptionsProvider

dotnet-method.NET
private static void ASPNET.StarterKit.Portal.Global.RegisterPasswordPolicyOptionsProvider()

把 Web 层运行期系统设置接入组件层密码策略。

Connects Web-layer runtime system settings to the component-layer password policy.

Localized Fields

remarks

位于独立组件项目，不能反向依赖 Web 配置读取器；因此启动期通过委托注入当前有效策略。读取失败时策略类自身会回退到硬下限默认值。

lives in the independent components project and must not depend back on the Web configuration resolver, so startup injects a delegate for the effective policy. The policy class falls back to its hard lower-bound defaults if reads fail.
