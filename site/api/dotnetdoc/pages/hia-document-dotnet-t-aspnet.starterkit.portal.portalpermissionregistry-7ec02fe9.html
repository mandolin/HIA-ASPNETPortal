门户权限定义注册表。

Registry of Portal permission definitions.

Localized Fields

remarks

注册表提供静态元数据、已知键名查询和规范化能力，不判断当前请求是否获权，也不表示任何角色已经拥有某个键名。

The registry provides static metadata, known-key lookup, and normalization only. It does not authorize the current request or imply that any role owns a key.
