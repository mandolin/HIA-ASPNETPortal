获取已绑定模块配置中的模块实例标识。

Gets the module-instance identifier from the bound module configuration.

Localized Fields

remarks

动态加载器必须先设置；该标识只定位模块实例，不证明 Portal 归属或当前用户授权，契约也不规定未绑定时的安全默认值。

The dynamic loader must setfirst; the identifier only locates a module instance, proves neither Portal ownership nor current-user authorization, and the contract defines no safe default before binding.
