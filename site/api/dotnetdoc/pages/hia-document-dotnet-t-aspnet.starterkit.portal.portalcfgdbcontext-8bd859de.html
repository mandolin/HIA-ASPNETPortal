Entity Framework data context used by portal structural configuration tables.

Localized Fields

remarks

该上下文负责旧 `PortalCfg_*` 模块定义、全局配置、Tab、模块实例和模块设置数据。业务数据、运行时日志和系统设置扩展表不通过此上下文维护。

This context owns legacy `PortalCfg_*` module definitions, global settings, tabs, module instances and module setting data. Business data, runtime logs and system-setting extension tables are maintained outside this context.
