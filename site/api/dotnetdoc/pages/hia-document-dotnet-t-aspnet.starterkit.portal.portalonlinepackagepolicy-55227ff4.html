PortalOnlinePackagePolicy

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalOnlinePackagePolicy

在线能力包在「隔离上传通道」阶段的集中安全策略：文件白名单、体积上限、条目名与条目类型白名单、服务端生成存储名。

Centralised safety policy for the isolated-upload stage of an online capability package: file allow-list, size limits, entry-name and entry-type allow-lists, and server-generated storage names.

remarks

本类型是纯函数策略，不读取文件、不读取数据库、不读取 HTTP 请求，也不执行解压或安装。所有判定 fail-closed：任何未知、缺失、超长或格式异常的输入一律拒绝，且不回显原始不可信文本。 依据 OWASP File Upload Cheat Sheet（allow-list、解码后校验、服务端生成文件名、大小上限、ZIP 高风险）、Microsoft Learn「Best practices for working with ZIP and TAR archives in .NET」（解压后大小与条目数上限、路径边界校验、ZIP 不推荐作为可信载体）。 本白名单只定义「隔离暂存阶段可落地」的文件类型，与 manifest v2 的资源解析链相互独立；后续安装校验只能在本白名单基础上收紧，不得放宽。

This type is a pure-function policy: it reads no file, database, or HTTP request and performs no extraction or installation. Every decision is fail-closed — unknown, missing, overlong, or malformed input is rejected, and raw untrusted text is never echoed. It follows the OWASP File Upload Cheat Sheet (allow-list, validation after decoding, server-generated names, size limits, ZIP as a high-risk carrier) and Microsoft Learn "Best practices for working with ZIP and TAR archives in .NET" (decompressed size and entry-count limits, destination-path validation). This allow-list defines only what may land in the isolated staging area; it is independent of the manifest v2 resource parser, and later installation checks may only narrow it, never broaden it.
