NavigationAnonymousHiddenNavigationKeys

dotnet-field.NET
public const string ASPNET.StarterKit.Portal.PortalSettingKeys.NavigationAnonymousHiddenNavigationKeys

**仅对匿名访客**隐藏的导航页签键集合。业务功能页签应列在此处： 登录用户看得见、匿名看不见 —— 避免"匿名看到入口、点进去却因未认证而无内容"（ADR 0027）。

Navigation tab keys hidden **from anonymous visitors only**. Business-capability tabs belong here: signed-in users see them while anonymous visitors do not, which prevents "anonymous sees the entry but the page has no content because it is unauthenticated" (ADR 0027).
