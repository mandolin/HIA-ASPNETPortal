显示指定员工号对应的低敏员工摘要。

Displays a low-sensitivity employee summary for the specified employee code.

remarks

查询只使用目录读取接口，不在摘要区暴露更高敏资料；员工不存在时只显示通用提示。

The lookup uses only the directory read contract and does not expose more sensitive data in the summary area; a missing employee shows a generic message.
