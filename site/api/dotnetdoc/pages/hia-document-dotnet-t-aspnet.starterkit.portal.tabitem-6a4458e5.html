该实体映射 `PortalCfg_Tabs`，保留旧门户的排序、角色字符串和移动端字段。访问授权仍由 `PortalSecurity`、`PortalSettings` 和页面装载流程统一解释。

This entity maps to `PortalCfg_Tabs` and preserves the legacy portal ordering, role-string and mobile fields. Access authorization is still interpreted by `PortalSecurity`, `PortalSettings` and page loading flow.
