TabSettings

dotnet-type.NET
ASPNET.StarterKit.Portal.TabSettings

封装门户中一个 Tab 的运行期设置快照。

Encapsulates the runtime settings snapshot for one portal tab.

Localized Fields

remarks

该对象由 `ITabItem` 投影而来，并实现排序接口，使旧代码可直接按 `TabOrder` 对 Tab 集合排序。

This object is projected from `ITabItem` and implements comparison so legacy code can sort tab collections by `TabOrder`.
