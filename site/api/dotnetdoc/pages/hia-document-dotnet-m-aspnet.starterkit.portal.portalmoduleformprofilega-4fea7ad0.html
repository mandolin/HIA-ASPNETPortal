IsHostFrameworkEnabled

dotnet-method.NET
public static ASPNET.StarterKit.Portal.PortalModuleFormProfileGate.Decision ASPNET.StarterKit.Portal.PortalModuleFormProfileGate.IsHostFrameworkEnabled(ASPNET.StarterKit.Portal.PortalModuleFormContract.FieldInput form, System.Collections.Generic.IList<string> allowSet)

判定宿主框架形态是否启用。`allowSet` 为 null 或空集 → 缺省关闭； `form` 未声明 → 不启用新形态（兼容既有包）；否则精确匹配允许集，未命中即 fail-closed。

Decides whether a host-framework form is enabled. A null/empty `allowSet` means default-off; an undeclared `form` enables no new form (legacy compatible); otherwise an exact allow-set match is required and a miss fails closed.
