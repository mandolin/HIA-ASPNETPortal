ASPNET.StarterKit.Portal.PortalEmptyStateRenderer

把"列表零条"这一状态渲染为表格内的单行提示。

Renders the "list has zero rows" state as a single in-table hint row.

remarks

P74.3 起供业务前后台列表复用。设计约束：① 空态必须是**表格内的一行**（表头保留、视觉连续），故输出 `/` 而非独立区块；② 样式类 `portal-empty-state` 作用于**内部的** —— 直接放在上会与表格既有的 `` 同属性竞争，而二者特异性相同或后者更高，居中会失效（真实渲染实测）；③ 调用方负责判断"空"与"筛选无结果"的**文案差异**，以及"读取失败"**不得**退化为空态。有数据时返回空字符串，使调用方无需分支。 tr td td div td .xxx td { text-align: left }

Reused by front-end and Admin business lists starting with P74.3. Design constraints: (1) the empty state must be a **row inside the table** so the header stays and the list reads continuously, hence `/` output rather than a detached block; (2) the `portal-empty-state` class applies to a**inside** the— putting it on theitself competes with existing `rules at equal or higher specificity, which breaks centering (measured in a real render); (3) the caller owns the **wording difference** between "no data" and "no matches", and must never degrade a **read failure** into an empty state. When rows exist the method returns an empty string so callers need no branch. tr td div td td .xxx td { text-align: left }
