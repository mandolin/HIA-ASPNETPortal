TabNameLocalizedJson

dotnet-property.NET
string ASPNET.StarterKit.Portal.ITabItem.TabNameLocalizedJson { get; set; }

页签名称的其它语言列，取值为以文化名为键的 JSON 对象（如 `{"ja-JP":"ホーム"}`）。 本契约只约定"是 JSON 文本"，键名是否为受支持的文化由解析器判定。

Other-languages column for the tab name, holding a JSON object keyed by culture name (for example `{"ja-JP":"ホーム"}`). This contract only requires JSON text; whether a key is a supported culture is decided by the resolver.
