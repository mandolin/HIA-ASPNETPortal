BuildTabEntryKey

dotnet-method.NET
public static string ASPNET.StarterKit.Portal.PortalNavigationVisibilityPolicy.BuildTabEntryKey(string tabName, string navigationKey)

构造主导航 Tab 的稳定入口键；**导航稳定键优先**，缺失时回退到 Tab 显示名称。

Builds the stable entry key of a main-navigation Tab; the **navigation stable key takes precedence**, falling back to the Tab display name when absent.

Localized Fields

remarks

为什么需要稳定键：页签名本地化后，同一页签在不同界面文化下显示名不同（`首页` / `Home`）， 管理员还可以把它改成任意文本。若键仍由显示名派生，registry 里登记的 `Tab.Home` 会在中文界面下失配， 门控静默退化为"未登记即放行" —— 那不是安全的放行，而是**权限检查凭空消失**。 迁移脚本已把存量页签名回填为稳定键，因此存量部署的 `Tab.*` 键逐字节不变。

Why a stable key is needed: once tab names are localized, the same tab displays differently per UI culture (`首页` / `Home`), and an administrator can rename it to anything. If the key were still derived from the display name, the registered `Tab.Home` would fail to match under the Chinese UI and the gate would silently degrade to "unregistered means allowed" — which is not a safe allow but the **vanishing of a permission check**. The migration backfills existing tab names as stable keys, so existing deployments keep their `Tab.*` keys byte-identical.

params.tabName.summary

门户配置中的 Tab 名称，作为稳定键缺失时的回退。

Tab name from portal configuration, used as the fallback when the stable key is absent.

params.navigationKey.summary

导航稳定键；为空时回退到 Tab 名称。

Navigation stable key; the Tab name is used when it is blank.

returns.summary

稳定入口键；Tab 名与稳定键均为空白时为空字符串。

Stable entry key; empty when both the Tab name and the stable key are blank.
