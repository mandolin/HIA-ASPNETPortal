TryDeprovision

dotnet-method.NET
bool ASPNET.StarterKit.Portal.IPortalModuleProvisioner.TryDeprovision(int moduleId, string packageId)

卸载：删除模块实例，并在其定义不再被任何实例引用时回收定义；同时清理包状态。返回是否已完成（实例不存在也视为已清理）。

Uninstall: removes the module instance, and reclaims the definition when no instance references it; also clears the package state. Returns whether it completed (a missing instance is treated as already cleaned).
