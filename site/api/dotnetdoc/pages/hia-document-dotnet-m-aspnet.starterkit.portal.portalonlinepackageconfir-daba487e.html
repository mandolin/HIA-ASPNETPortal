TryConfirm

public static bool ASPNET.StarterKit.Portal.PortalOnlinePackageConfirmationGate.TryConfirm(ASPNET.StarterKit.Portal.PortalOnlinePackageConfirmationTicket ticket, string antiForgeryToken, string actorName, string currentPackageHash, string confirmPermissionKey, bool confirmGranted, System.DateTime confirmedUtc, out ASPNET.StarterKit.Portal.PortalOnlinePackageConfirmationTicket consumedTicket, out bool replayed, out string reason)

在「确认安装」时校验票据并二次鉴权；通过时返回已消费票据，重复提交以幂等方式拒绝二次安装。

Validates the ticket and re-authorizes at "confirm install"; returns a consumed ticket on success, while a repeated submission is rejected idempotently.

Localized Fields

remarks

判定顺序刻意固定：票据存在 → 时间 → 防伪令牌 → 账号 → 包哈希 → 权限键 → 权限结论 → 幂等消费。 每一步都在「未产生副作用」前完成，且失败时不改变票据、不消费、不安装。 **幂等语义**：已消费票据在通过全部校验后返回 `replayed=true`，调用方据此跳过安装动作，而不是报错或重复安装。

The order is deliberately fixed: ticket present → time → anti-forgery token → actor → package hash → permission key → verdict → idempotent consumption. Every step completes before any side effect, and a failure neither mutates the ticket, consumes it, nor installs anything. **Idempotency semantics**: a consumed ticket that passes every check returns `replayed=true`, so callers skip installation rather than erroring or installing twice.

Anti-forgery synchroniser token returned by the hidden form field.

params.actorName.summary

当前已认证账号名，须与签发票据时一致。

Current authenticated account name; must match the issuing actor.

params.currentPackageHash.summary

确认时重新计算的暂存包哈希，用于检测包被替换。

Hash recomputed for the staged package at confirmation, detecting package substitution.

params.confirmPermissionKey.summary

页面层判定的确认权限键，必须是 Module.OnlinePackage.Confirm。

Confirm permission key judged by the page layer; must be Module.OnlinePackage.Confirm.

params.confirmGranted.summary

页面层已判定的确认权限结果；false 一律拒绝。

Page-layer confirm permission verdict; false is always rejected.

params.confirmedUtc.summary

确认时间（UTC），由调用方提供。

Confirmation time (UTC), supplied by the caller.

params.consumedTicket.summary

首次成功时为已消费票据；幂等重放时返回原已消费票据；失败时为 null。

Consumed ticket on first success, the original consumed ticket on idempotent replay, null on failure.

params.replayed.summary

true 表示这是已消费票据的幂等重放，调用方不得再次执行安装。

True indicates an idempotent replay of a consumed ticket; callers must not install again.

params.reason.summary

拒绝原因的稳定短语，不回显票据或令牌内容。

Stable rejection phrase that never echoes ticket or token content.

returns.summary

允许确认（首次或幂等重放）时为 true；任何拒绝为 false。

True when confirmation is allowed (first use or idempotent replay); false on any rejection.
