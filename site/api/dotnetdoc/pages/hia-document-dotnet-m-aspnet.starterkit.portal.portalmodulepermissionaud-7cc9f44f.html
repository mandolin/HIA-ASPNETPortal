边界③机器核对：能力标识须在调用方传入的封闭能力词表内（第三方不得自创能力条目）。 未声明能力（null / 空白）按既有 Provisioner 条件口径不阻断。

Machine check for boundary 3: a capability id must be in the caller-supplied closed registry (no self-created capability). An undeclared capability (null/blank) is not blocked, matching the existing conditional Provisioner rule.
