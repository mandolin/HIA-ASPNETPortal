GetVisibleEventsForItems

dotnet-method.NET
ASPNET.StarterKit.Portal.ICollaborationItemDb.GetVisibleEventsForItems(System.Collections.Generic.IList<long>, int) /* return type unavailable */

批量读取多个事项对当前用户可见的时间线，用于消除列表逐行读取造成的 N+1 查询。

Reads the timelines of several items visible to the current user in one batch, removing the N+1 queries caused by per-row reads in a list.

Localized Fields

remarks

语义与逐条等价：动作人授权只计算一次，但**每个事项仍逐个执行与校验**（安全约束不得为性能合并掉）；未被授权或不存在的事项在结果中为空列表，使调用方无需区分内部状态。返回的字典**包含全部请求标识**（无事件者为空列表），条目内顺序与逐条读取一致。空输入、schema 不可用或读取失败时返回全部为空列表的结果。 CanParticipate CanView

Semantically equivalent to the per-item: actor authorization is computed once, yetandare still evaluated **for every item individually** (a security constraint that must not be collapsed for performance). Items that are unauthorized or missing appear as empty lists so callers never distinguish internal states. The returned dictionary **contains every requested identifier** (empty list when no events exist) and preserves the per-item ordering of the single-item read. Empty input, unavailable schema, or read failure yields all-empty lists. CanParticipate CanView
