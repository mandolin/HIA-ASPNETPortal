导航可见性判定所需的当前上下文（纯数据，不读取 HttpContext、数据库或配置）。

Current context required for navigation visibility decisions (pure data; it reads no HttpContext, database, or configuration).

remarks

Web 项目负责用 PortalAuthorization、Profile resolver 等组装本对象，再交给 PortalNavigationVisibilityPolicy 判定；这样判定逻辑保持纯内存、可被 Portal.Tests 覆盖。

The web project assembles this object from PortalAuthorization, the Profile resolver, and similar sources, then hands it to PortalNavigationVisibilityPolicy; this keeps decisions pure in-memory and testable by Portal.Tests.
