创建或更新用户的强哈希凭据记录。

Creates or updates a user's strong-hash credential record.

Localized Fields

remarks

要求凭据和安全状态表同时存在；密码只传给哈希器，持久化哈希、盐、格式和迭代次数，不保存明文。调用方负责在适当事务中提交上下文。

Requires both credential and security-state tables. The password is passed only to the hasher; persisted fields are hash, salt, format, and iteration count, never plaintext. The caller is responsible for committing the context in the appropriate transaction.
