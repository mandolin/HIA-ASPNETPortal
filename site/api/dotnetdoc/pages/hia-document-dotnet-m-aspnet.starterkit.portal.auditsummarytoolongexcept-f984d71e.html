public ASPNET.StarterKit.Portal.AuditSummaryTooLongException.AuditSummaryTooLongException(int actualLength, int maxLength, string context)

创建异常并携带实际长度、最大长度与子系统上下文；上下文只用于让诊断消息指明是哪一类审计摘要， 不改变 fail-closed 语义。既有装配态调用方走两参数重载，消息保持原样。

Creates the exception carrying actual length, maximum length, and a subsystem context; the context only labels which audit summary overflowed in diagnostics and does not change fail-closed semantics. Existing assembly-state callers use the two-argument overload and keep their original message.
