TryReadPackage

dotnet-method.NET
ASPNET.StarterKit.Portal.PortalModuleCatalog.TryReadPackage(string, ASPNET.StarterKit.Portal.PortalModulePackage&, string&) /* return type unavailable */

按目录名读取并验证一个受信任部署模块包。

Reads and validates one trusted-deployment module package by directory name.

Localized Fields

remarks

该私有读取链只验证既有部署内容，不安装、修复或修改任何文件；成功也不代替 Profile、状态表、路由或页面授权。

This private read chain validates existing deployment content only and never installs, repairs, or modifies files; success also does not replace profile, state-table, routing, or page-authorization gates.

params.directoryName.summary

`DesktopModules` 直接子目录的候选名称；必须先通过受控目录名规则。

Candidate name of an immediate `DesktopModules` child directory; it must first pass the controlled directory-name rule.

params.package.summary

成功时返回不可变受信任包快照；失败时保持 null。

Returns an immutable trusted-package snapshot when successful; it remains null on failure.

params.reason.summary

不含物理路径、原始 manifest 或异常详情的受控失败原因。

Controlled failure reason that contains no physical path, raw manifest, or exception detail.

returns.summary

目录、manifest、入口和资源均通过当前受控校验时为 true。

True when the directory, manifest, entry, and resources all pass current controlled validation.
