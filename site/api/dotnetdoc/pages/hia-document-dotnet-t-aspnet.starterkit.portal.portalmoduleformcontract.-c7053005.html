FieldInput

dotnet-type.NET
struct ASPNET.StarterKit.Portal.PortalModuleFormContract.FieldInput

形态字段校验输入；`declared` 表示字段是否在 manifest 出现，`isString` 表示值是否为 JSON 字符串。 不声明字段（declared=false）时不校验其值，保证既有包兼容。

Input for a form-field check: `declared` says whether the field is present in the manifest, `isString` says whether the value is a JSON string. Undeclared fields (declared=false) skip value checks for backward compatibility.
