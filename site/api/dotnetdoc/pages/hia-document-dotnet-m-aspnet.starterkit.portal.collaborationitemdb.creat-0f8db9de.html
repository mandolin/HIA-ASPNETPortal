CreateSubmittedItem

ASPNET.StarterKit.Portal.CollaborationItemDb.CreateSubmittedItem(ASPNET.StarterKit.Portal.CollaborationItemCreateRequest) /* return type unavailable */

规范化并校验创建请求后，创建一条处于状态的协同事项及其 Submit 事件。 Submitted

Normalizes and validates a create request, then creates a collaboration item instatus with its Submit event. Submitted

Localized Fields

remarks

本方法仅写入事项事实和 Submit 事件，两者通过同一参数化数据库命令批次提交；待办投影和运营审计由调用页面在业务事实成功后作为旁路处理。

This method writes only the item fact and Submit event through one parameterized database-command batch; the calling page handles work-item projection and operational audit as sidecars after the business fact succeeds.

params.request.summary

由已认证页面层提供的事项输入；发起人、标题和至少一个负责人目标为必填项。

Item input supplied by an authenticated page layer; initiator, title, and at least one owner target are required.

returns.summary

成功时包含新事项标识和事项编码；校验、参考数据或数据库失败时返回不含内部异常详情的失败结果。

On success, contains the new item identifier and item code; validation, reference-data, or database failures return a result without internal exception detail.
