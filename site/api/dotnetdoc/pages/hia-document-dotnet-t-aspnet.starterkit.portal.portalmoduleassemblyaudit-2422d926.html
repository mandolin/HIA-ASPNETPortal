PortalModuleAssemblyAuditFormatter

dotnet-type.NET
class ASPNET.StarterKit.Portal.PortalModuleAssemblyAuditFormatter

模块装配态审计载荷的六要素结构化紧凑格式器（纯函数，不依赖 Web 上下文、不读取台账、不改变装配态）。 格式与离线工具 Invoke-PortalModuleAssemblyCheck.ps1 使用同一字段顺序，确保两份产物可互相印证。目的载体是 PortalCfg_OperationAudits 的 Summary 列。

Structured compact formatter for the six-element module-assembly-state audit payload (pure function; no Web context, no ledger read, no assembly-mode change). Field order matches the offline tool Invoke-PortalModuleAssemblyCheck.ps1 so the two artifacts corroborate each other. The carrier is the Summary column of PortalCfg_OperationAudits.

Localized Fields

remarks

超长时抛 AuditSummaryTooLongException（fail-closed），绝不静默截断导致六要素缺失；调用方须据此走审计表扩展方案。本类只负责格式化，不负责写入——写入由 Web 项目中的 PortalModuleAssemblyAudit 包装调用 PortalOperationAudit.Record。

On overflow it throws AuditSummaryTooLongException (fail-closed) rather than silently truncating and dropping elements; callers must take the audit-table extension path. This class only formats; writing is done by the PortalModuleAssemblyAudit wrapper in the Web project via PortalOperationAudit.Record.
