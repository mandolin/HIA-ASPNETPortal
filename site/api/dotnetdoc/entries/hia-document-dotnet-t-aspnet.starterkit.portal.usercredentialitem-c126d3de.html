本表与旧并行存在，作为 P5.2 渐进迁移的正式凭据来源。 旧字段只用于尚未升级用户的首次兼容验证；一旦本表存在记录，登录不得回退到旧 MD5 字段。 Portal_Users.Password

This table coexists with the legacycolumn as the official credential source for the P5.2 gradual migration. The legacy column is used only for the first compatibility check of users that have not yet been upgraded; once this record exists, sign-in must not fall back to legacy MD5. Portal_Users.Password
