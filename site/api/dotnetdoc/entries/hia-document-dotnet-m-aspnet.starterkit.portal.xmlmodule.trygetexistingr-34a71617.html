校验模块设置中的资源路径，并确认对应物理文件存在。

Validates a configured resource path and confirms that the mapped physical file exists.

Localized Fields

remarks

该方法集中处理路径策略和 `Server.MapPath` 文件存在性检查，调用方只根据布尔结果决定是否显示中性提示。

This method centralizes path-policy checks and `Server.MapPath` file-existence checks; callers only use the Boolean result to decide whether to show a neutral notice.

params.configuredPath.summary

模块设置中的原始 XML 或 XSL/T 路径。

The raw XML or XSL/T path from module settings.

params.normalizedPath.summary

通过受信任部署资源策略后的应用相对路径；失败时为空字符串。

The application-relative path after trusted-deployment resource normalization; empty when validation fails.

returns.summary

路径满足策略且物理文件存在时返回 `true`。

Returns `true` when the path passes policy checks and the physical file exists.
