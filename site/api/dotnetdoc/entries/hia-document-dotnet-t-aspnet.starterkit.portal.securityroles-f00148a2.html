remarks

角色名称始终从当前门户的 roleId 读取，不信任 URL 中的显示名称。角色成员增删不会立即撤销 目标用户的既有角色 Cookie。

The role name is always read from the current Portal roleId and never trusted from a URL display value. Adding or removing membership does not immediately revoke the target user's existing role cookie.
