Localized Fields

remarks

`"system"` 是**身份缺失时的兜底字面量**，不是真实身份：它只表示"本次创建未记录到具体操作者"， 审计与排查不得据此判定为系统自动执行。该兜底**不替代调用方传递身份的责任** —— 需要可追溯的创建者时调用方必须显式传入，否则审计链在该记录上断掉。

`"system"` is a **fallback literal for a missing identity**, not a real identity: it only means "this creation recorded no specific actor", and audits or troubleshooting must not read it as automatic system execution. The fallback **does not replace the caller's duty to pass identity** — when a traceable creator is required the caller must pass it explicitly, otherwise the audit chain breaks on that record.

params.request.summary

调用方提交的原始创建请求，可为空。

The raw creation request from the caller, which may be null.

returns.summary

裁剪长度、补齐默认 UTC 时间和系统操作者后的创建请求。

The creation request after trimming lengths and filling default UTC time and system actor.
