public bool ASPNET.StarterKit.Portal.PortalModuleAssemblyState.HasCodeFileEntries()

判断台账中是否存在显式登记的受控调试态条目，供部署级开关与封版前复核点作为判定输入。

Determines whether the ledger contains any explicitly registered controlled-debug-mode entry, serving as input to the deployment-level switch and the pre-release review point.

Localized Fields

remarks

这是"环境开关该不该拦"的纯函数判据，不读取配置、不读取请求、不修改任何状态；实际接线由部署侧与封版前复核门禁完成，本方法不实施页面授权。

This is the pure predicate behind "whether the environment switch should block"; it reads no config or request and mutates no state. Actual wiring belongs to deployment and the pre-release review gate; this method implements no page authorization.

returns.summary

至少一个条目的装配态为 CodeFile 时为 true；全缺省或仅 CodeBehind 时为 false。

True when at least one entry is CodeFile; false for an all-default or CodeBehind-only ledger.
