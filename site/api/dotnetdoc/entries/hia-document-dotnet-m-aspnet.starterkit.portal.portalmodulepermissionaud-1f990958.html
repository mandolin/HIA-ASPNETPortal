public static ASPNET.StarterKit.Portal.PortalModulePermissionAuditContract.Decision ASPNET.StarterKit.Portal.PortalModulePermissionAuditContract.IsAuditRecordWellFormed(string category, string action, string outcome, System.Collections.Generic.IList<string> registeredCategories, System.Collections.Generic.IList<string> registeredActions)

判定运营审计记录：类别 / 动作须在调用方传入的已登记词表内，outcome 须在 `Success` / `Failure` / `Skipped` 白名单内（与 `PortalOnlinePackageAuditFormatter.IsRegisteredOutcome` 同口径）。 拒绝未知 outcome 即为「不伪造成功记录」。

Decides whether an operations-audit record is well formed: category and action must be in the caller-supplied registered vocabularies, and outcome must be in the `Success`/`Failure`/`Skipped` allow-list (same rule as `PortalOnlinePackageAuditFormatter.IsRegisteredOutcome`). Rejecting an unknown outcome enforces "no fabricated success".
