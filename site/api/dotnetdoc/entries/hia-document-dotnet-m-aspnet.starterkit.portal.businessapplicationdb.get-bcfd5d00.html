读取指定门户用户的最新申请查询快照。

Reads a newest-first application query snapshot for a specified Portal user.

Localized Fields

remarks

非正用户标识、架构不可用或查询异常返回空列表；空列表不能区分无申请与读取失败。方法只按标识过滤，不负责证明当前请求用户确实拥有该标识。

Non-positive user identifiers, unavailable schema, and query failures return an empty list; an empty list cannot distinguish no applications from a read failure. The method filters by identifier only and does not prove that the current request user owns that identifier.

params.applicantUserId.summary

正数申请人门户用户标识；非正数直接返回空列表。

Positive applicant Portal user identifier; non-positive values return an empty list.

params.take.summary

期望最大条数；实现对非正数使用 10，并把上限限制为 200。

Requested maximum count; the implementation uses 10 for non-positive values and caps the count at 200.

returns.summary

按提交时间和主键倒序的可变投影列表。

A mutable projection list ordered by submission time and then primary key descending.
