remarks

能力是抽象分类，模块是声明方。本定义只登记能力键、所属层、生命周期、主责模块与权限键前缀，不收模块实现细节，也不授予任何权限。

A capability is an abstract classification while modules are the declaring side. This definition only registers the capability key, layer, lifecycle, primary module, and permission-key prefix; it holds no module implementation detail and grants no permission.
