生成按展示顺序排列的「分组 → 成员页签键」只读视图，供 `[已脱敏]` 的渲染层消费。 未分组页签由调用方平铺展示；本方法不读数据库、不读请求上下文、不做授权判定。

Produce a read-only, presentation-ordered "group → member tab key" view for the `[已脱敏]` renderer. Ungrouped tabs are rendered flat by the caller; this method reads no database or request context and performs no authorization.
