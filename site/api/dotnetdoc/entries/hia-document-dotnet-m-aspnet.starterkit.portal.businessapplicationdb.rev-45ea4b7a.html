在仍可审核的申请上执行受控审核动作，并记录 WorkflowEvent。

Applies a controlled review action to a still-reviewable application and records a WorkflowEvent.

Localized Fields

remarks

动作键只映射到固定状态；更新条件限制为 Submitted/InReview。空请求、非法动作、未找到可审核申请、架构不可用和 SQL 异常均返回低敏结果；审核授权必须由调用方在进入本方法前完成。

Action keys map only to fixed statuses, and the update is limited to Submitted/InReview. Null requests, unsupported actions, no reviewable application, unavailable schema, and SQL exceptions return low-sensitivity results; callers must authorize the review before entering this method.

params.request.summary

审核参数；实现会复制、裁剪并补默认值，不修改调用方实例。

Review parameters. The implementation copies, trims, and defaults the values without mutating the caller instance.

returns.summary

成功时包含申请标识和编号；失败时只提供可展示的低敏说明。

The application identifier and code on success, or only a display-safe low-sensitivity explanation on failure.
