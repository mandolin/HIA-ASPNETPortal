public static ASPNET.StarterKit.Portal.PortalNavigationGroupView.NavigationView ASPNET.StarterKit.Portal.PortalNavigationGroupView.Build(System.Collections.Generic.IList<ASPNET.StarterKit.Portal.ITabItem> authorizedTabs, int activeTabId, string configuration, System.Collections.Generic.IDictionary<int, string> blockedReasons, System.Globalization.CultureInfo culture)

从已授权页签集合构造两级分组视图。授权过滤必须在此**之前**由调用方完成；本方法只按 `NavigationKey` 查封闭词表与部署别名覆盖，不改变页签集合、不做权限判定。

Build the two-level grouped view from an already authorized tab collection. Authorization filtering must be completed by the caller **before** this call; this method only looks up `NavigationKey` in the closed vocabulary and deployment alias overrides, never changing the collection or deciding permissions.
