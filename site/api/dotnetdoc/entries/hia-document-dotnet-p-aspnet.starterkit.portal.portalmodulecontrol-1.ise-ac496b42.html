remarks

首次读取将全局 AlwaysShowEditButton 展示选项与当前请求对的角色布尔判断合并，并把结果以 1/2 缓存在本控件实例。后续读取不重新获取 Portal 设置、角色或模块配置；该提示不能授权保存、删除、管理或数据读取。

The first read combines the global AlwaysShowEditButton display option with the current request's Boolean role check against, then caches the result as 1 or 2 in this control instance. Subsequent reads do not re-fetch Portal settings, roles, or module configuration; the hint cannot authorize save, delete, administration, or data reads.
