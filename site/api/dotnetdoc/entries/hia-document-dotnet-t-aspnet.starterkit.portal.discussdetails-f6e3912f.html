remarks

此页面是旧 DesktopModule 的典型 code-behind：读取请求中的模块和消息标识，按模块编辑权限切换编辑 UI，并在展示前对历史 HTML 编码文本做规范化。P15.2 将它作为模块页面注释样例之一。

This page is a typical legacy DesktopModule code-behind: it reads module and message identifiers from the request, switches editing UI by module edit permission, and normalizes historically HTML-encoded text before display. P15.2 uses it as one module-page annotation sample.
