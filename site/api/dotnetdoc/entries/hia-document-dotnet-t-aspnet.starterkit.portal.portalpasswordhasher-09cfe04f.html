remarks

此类只在数据访问层内部使用。默认采用 PBKDF2-HMAC-SHA256，并把迭代次数写入每条凭据，便于之后按用户渐进提高成本参数。调用方不得记录输入密码、盐或哈希。

This helper is used only inside the data-access layer. It defaults to PBKDF2-HMAC-SHA256 and stores the iteration count on each credential, allowing later per-user cost upgrades. Callers must not log the submitted password, salt, or hash.
