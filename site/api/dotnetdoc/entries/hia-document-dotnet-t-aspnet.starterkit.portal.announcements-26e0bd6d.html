dotnet-type.NET
ASPNET.StarterKit.Portal.Announcements

显示公告列表，并仅为符合地址策略的“查看更多”链接生成可点击地址。 公告展示用户控件的 Designer 字段容器；字段由 ASCX 服务器控件生成。

Renders announcements and creates clickable Read More URLs only when they pass the navigation policy. Designer field container for the announcements display user control; fields are generated from ASCX server controls.

Localized Fields

remarks

公告正文由标记层控件负责编码显示；本控件只在 URL 输出处追加站内/受信任地址策略，避免旧记录把危险地址重新渲染成链接。

Announcement text is encoded by the markup controls; this control only applies the in-site/trusted URL policy at URL output so legacy records cannot render unsafe addresses as links.
