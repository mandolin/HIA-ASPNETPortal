class ASPNET.StarterKit.Portal.PortalModuleIsolationContract

入口注册与失败隔离的**纯内存只读契约判定器**。三项判定： ① 入口在单一真源中唯一（复用 `PortalNavigationRegistry` 的条目形状，不新增 registry）； ② 单模块失败可隔离（失败被记录且渲染循环 `continue`，其它模块继续）； ③ 诊断记录字段齐备且类别在调用方传入的已登记词表内（不新建第二套审计链）。 **不接入装载链、不读文件/配置、不写任何内容**。

Pure in-memory read-only contract decisions for entry registration and failure isolation: (1) an entry is unique in the single source of truth (reusing `PortalNavigationRegistry` entry shape, no new registry); (2) a single module failure is isolated (recorded and the render loop continues, other modules still render); (3) the diagnostic record is well formed and its category is in the caller-supplied registered vocabulary (no second audit chain). It is NOT wired into the loading chain and reads/writes no file or config.
