本类是 P64 状态机显式化的核心：把原先散落在 SQL 字符串与if-链中的两份事实收敛成一份可单测的数据。动作到目标状态在当前设计中唯一（即同一动作不论从哪个当前状态出发，目标相同），因此与可由本表派生；数据库写入守卫的 SQL 谓词也由生成，避免与表漂移。本类不读取数据库、不依赖 HTTP 上下文，可在单测中直接验证。 MapActionToStatus MapActionToStatus

This class is the core of the P64 state-machine explicitization: it collapses the two earlier fact copies—the SQL string and theif-chain—into one testable dataset. The action-to-target mapping is unique in the current design (an action always reaches the same target regardless of the source status), soandderive from this table; the SQL predicate used as the database write guard is also generated byto avoid drift. The class reads no database and depends on no HTTP context, so it can be verified directly in unit tests. MapActionToStatus MapActionToStatus
