remarks

该接口沿用旧讨论模块的线程模型：顶级主题按模块读取，回复线程按父级路径读取。调用方负责模块访问、模块编辑权限、父消息归属和展示层 HTML 编码。 DisplayOrder

This interface keeps the legacy discussion threading model: top-level topics are read by module, and reply threads are read by theparent path. Callers own module access, module-edit authorization, parent-message ownership checks, and presentation-layer HTML encoding. DisplayOrder
