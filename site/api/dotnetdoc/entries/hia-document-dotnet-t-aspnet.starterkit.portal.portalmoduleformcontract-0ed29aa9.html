class ASPNET.StarterKit.Portal.PortalModuleFormContract

模块形态描述字段的**只读契约校验器**。按 `module.json` 的四类形态维度 （模块种类 / 宿主框架 / 入口形态 / 资源与依赖声明）做封闭词表校验； **不接入装载链、不改变既有包解析结果、不读文件/配置、不写任何内容**。 字段缺失＝未声明（兼容既有包）；字段出现但值非法＝fail-closed。 本类零外部依赖：只接收调用方已从 manifest 提取的字符串与字符串集合， 由调用方负责把 JSON 类型错误映射为 "isString: false"。

Read-only contract validator for module form-description fields across the four dimensions (module kind / host framework / entry form / resources and dependency declarations). It performs closed-vocabulary validation only: it is NOT wired into the loading chain, does NOT change existing package parsing, reads no file/config, and writes nothing. A missing field means "undeclared" (backward compatible); a present but invalid value fails closed. This class has zero external dependencies: callers pass already-extracted strings and string collections; the caller maps JSON type errors to "isString: false".
