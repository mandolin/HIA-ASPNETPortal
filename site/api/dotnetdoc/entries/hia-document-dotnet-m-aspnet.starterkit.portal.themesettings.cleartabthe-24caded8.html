清除选定 Tab 的主题覆盖值。

Clears the theme override for the selected tab.

清除后当前 Tab 回退已解析全局主题；写入失败时保留原覆盖值，并由状态存储记录诊断。

After clearing, the current Tab falls back to the resolved global theme; on a write failure the existing override remains and diagnostics are recorded by the state store.
