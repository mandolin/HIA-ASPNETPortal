在线能力包审计的运行时写入包装（承载于 Web 项目，依赖 `PortalOperationAudit`）。 `summary` 应为 `PortalOnlinePackageAuditFormatter` 的产物（已确保 ≤500 且不截断）。 本类不读取隔离暂存文件、不改变装配态、不执行安装、不生成 SQL。

Runtime write wrapper for online capability package audits (lives in the Web project, depends on `PortalOperationAudit`). `summary` should be the output of `PortalOnlinePackageAuditFormatter` (already guaranteed ≤500 and non-truncated). This class reads no isolated staging file, changes no assembly mode, performs no installation, and generates no SQL.

remarks

**工具不代写**：离线工具只生成可审阅产物，绝不调用本类；审计记录由运行期在审批通过后写入。 写入经 `PortalOperationAudit.Record`，为 best-effort（失败只记诊断、不冒泡），因此审计只用于追溯， **不是**安装是否发生的授权或事实依据。动作与结果值在调用前由 Components 层词表校验，未知值直接拒绝写入。 **A 级硬边界**：`targetId` 只用服务端生成的隔离暂存名，不用包内声明标识、来源或 capability 作为身份/授权依据； 摘要不含一次性票据 nonce、防伪令牌、口令或连接串。

**Tools never write on behalf of runtime**: offline tools emit reviewable artifacts only and never call this class; audit records are written at runtime after approval. Writes go through `PortalOperationAudit.Record` and are best-effort (failures only log diagnostics, never bubble), so audit serves traceability and is **not** proof or authorization that an installation occurred. Actions and outcomes are validated against the Components-layer vocabulary before the call; unknown values are refused outright. **A-level hard boundary**: `targetId` uses only the server-generated isolated staging name, never a package-declared id, origin, or capability as an identity/authorization basis; summaries contain no ticket nonce, anti-forgery token, password, or connection string.
