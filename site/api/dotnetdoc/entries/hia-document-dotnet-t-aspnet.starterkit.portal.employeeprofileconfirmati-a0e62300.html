remarks

本视图只包含第一版允许员工自查的低敏基础字段和最近确认状态，不包含身份证号、手机号、 薪资、绩效等高敏字段。

This view contains only low-sensitivity foundation fields and the latest confirmation state allowed for employee self-check in the first version. It excludes high-sensitivity fields such as government ids, mobile phone numbers, compensation, and performance data.
