class ASPNET.StarterKit.Portal.PortalOnlinePackageRollbackDrill

在线能力包回滚演练判定器（纯逻辑、无状态、不触文件 IO）：把「校验 → 备份 → 还原 → 零残留」的 **结论判定**与「实际文件操作」分离，使演练证据可被单测逐项验证，而不依赖真实站点或数据库。

Decision maker for online capability package rollback drills (pure, stateless, no file IO): separates the **verdict** of "validate → backup → restore → zero residue" from actual file operations, so drill evidence is unit-testable without a live site or database.

remarks

证明边界（沿用 `[已脱敏]` / `[已脱敏]` 定稿口径）：演练只证明「受控快照可还原为与偏离前 逐字节一致且零残留」，**不表示真实回滚发生、不表示安装发生、不表示运行期装配态被切换**。 三种情形（校验失败 / 备份损坏 / 复核点未通过）各自的判定结果必须如实记录，不得把拒绝包装成成功。

Proof boundary (following the `[已脱敏]` / `[已脱敏]` ruling): a drill proves only that "the controlled snapshot restores byte-identically to the pre-divergence state with zero residue"; it **does not** mean a real rollback occurred, an installation occurred, or a runtime assembly mode was switched. Each of the three scenarios (validation failed / backup corrupted / checkpoint rejected) must record its verdict honestly; a rejection is never wrapped as success.
