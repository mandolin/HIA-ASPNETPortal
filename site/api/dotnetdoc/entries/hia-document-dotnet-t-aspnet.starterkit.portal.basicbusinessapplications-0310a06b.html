基础业务模块的"存库词汇"单一字面源：Leave/Expense 在库中持久化为这些值（Pending/Approved/Rejected/Returned/Closed）。规范展示词经 BusinessApplicationLifecycle.NormalizeToCanonical 映射（Pending→Submitted 等）。本类只承载存库常量、消除按模块重复的字面量；展示语义见 PortalBusinessApplicationStatuses。

Single source of the stored vocabulary for basic-business modules: Leave/Expense persist these values (Pending/Approved/Rejected/Returned/Closed) in the database; canonical display words are mapped via BusinessApplicationLifecycle.NormalizeToCanonical (Pending→Submitted etc.). This class carries only the stored constants to remove per-module duplicated literals; display semantics live in PortalBusinessApplicationStatuses.
