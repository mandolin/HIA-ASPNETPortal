public static bool ASPNET.StarterKit.Portal.PortalOnlinePackagePolicy.TryValidatePackageFile(string clientFileName, int compressedSize, out string reason)

校验一次包上传的客户端文件名与压缩体积；不读取文件内容，也不信任 Content-Type。

Validates the client file name and compressed size of one package upload; it reads no file content and trusts no Content-Type.

The file name is used only to read its extension and for display; it never contributes to a storage path — CreateStorageName generates physical names server-side.
