门户用户的会话安全版本状态。

Session security-version state for a Portal user.

Localized Fields

remarks

安全版本写入 Forms Authentication 票据和角色 Cookie。密码重置、角色成员关系变化等高价值状态变更会递增该版本，从而让旧票据在下一次请求时失效。

The security version is written into both the Forms Authentication ticket and the role cookie. High-value state changes such as password reset or role-membership updates increment the version so older tickets become invalid on the next request.
