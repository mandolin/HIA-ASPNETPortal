public const string ASPNET.StarterKit.Portal.PortalPermissionKeys.ModuleOnlinePackageConfirm

确认安装已通过校验的隔离暂存包（第二步）：必须由独立账号动作显式触发，并与上传动作分离判定权限， 防止「上传即安装」被单步跳过。与 `Module.OnlinePackage.Upload` 不共用同一键，确保双步确认闸可在服务端二次鉴权。 **A 级硬边界**：来源与能力声明永不作为授权依据；本键不授予 `Admins` 角色，也不扩大任何角色到管理员作用域。

Confirm installation of a validated, isolated staged package (step two): must be explicitly triggered by a separate account action, with permission judged independently of the upload action so "upload means installed" cannot be skipped in one step. It does not share a key with `Module.OnlinePackage.Upload`, letting the two-step gate re-authorize on the server. **A-level hard boundary**: origin and capability claims are never an authorization basis; this key grants no `Admins` role and extends no role into administrator scope.
