class ASPNET.StarterKit.Portal.PortalBusinessApplicationTransition

业务申请的一条合法迁移：动作、目标状态、合法来源状态集合，以及该动作是否走后台审核路径。

One legal business-application transition: the action, its target status, the set of legal source statuses, and whether the action travels the administration review path.

remarks

本类型只是数据行，不含判断逻辑；判断集中在，便于单测与派生 SQL 守卫。`ViaReviewPath` 用于把"审核类动作"与"申请人自助动作"分开——只有前者参与后台审核 SQL 的状态谓词，避免自助动作被后台路径意外触发。

This type is only a data row and holds no judgement logic; the judgements live inso they can be unit tested and used to derive the SQL guard. `ViaReviewPath` separates review actions from applicant self-service actions: only the former participate in the administration review SQL predicate, so a self-service action cannot be triggered accidentally through the review path.
