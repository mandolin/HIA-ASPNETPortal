remarks

第一版只允许已登录且拥有 Active 员工绑定的用户提交低敏字段级文本更正请求；请求进入后台处理页， 本模块不直接修改员工主数据。

The first version allows only signed-in users with an active employee binding to submit low-sensitivity field-level text correction requests. Requests go to an administration page; this module does not directly modify employee master data.
