BuildGroupTabUrl

dotnet-method.NET
protected string ASPNET.StarterKit.Portal.DesktopPortalBanner.BuildGroupTabUrl(object dataItem)

为分组页签构造地址，使用视图里保存的**最终集合显示下标**，而不是组内位置； 否则两级分组会改变 `tabindex` 口径，使页面内匿名登录模块的注入启发式漂移。

Build a group-tab URL using the view's **final collection display index** rather than the in-group position; otherwise two-level grouping would change `tabindex` semantics and drift the in-page anonymous-login heuristic.
