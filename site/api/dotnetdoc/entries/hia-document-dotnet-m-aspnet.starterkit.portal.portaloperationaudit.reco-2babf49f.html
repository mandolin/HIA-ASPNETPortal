尽力写入一条高价值状态变化的运营审计记录；默认记录成功事实（outcome="Success"），安全类必需事件（认证失败、授权失败）可显式传入 outcome="Failure" 以记录真实的失败事实。

Best-effort writes one operations-audit record for a high-value state change; it records a success fact by default (outcome="Success"), and security-critical required events (authentication failures, authorization failures) may pass outcome="Failure" to record a genuine failure fact.
