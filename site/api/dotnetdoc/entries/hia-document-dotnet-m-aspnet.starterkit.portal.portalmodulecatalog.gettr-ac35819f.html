获取所有通过受信任部署目录与 manifest 校验的模块包。

Gets every module package that passes trusted-deployment directory and manifest validation.

Localized Fields

remarks

该方法只发现与验证候选部署包，不读取模块状态表、不解析 Profile、不授予页面访问，也不加载控件或资源。

This method only discovers and validates candidate deployment packages; it does not read the module-state table, resolve profiles, grant page access, or load controls or resources.

returns.summary

按显示名和稳定包标识排序的只读可信包列表；目录/manifest 无效或稳定标识重复的包不会出现。

Read-only trusted-package list ordered by display name and stable package identifier; packages with invalid directory/manifest data or duplicate stable identifiers are absent.
