按事件编号读取一条结构化诊断日志。

Finds one structured diagnostic entry by event id.

remarks

事件编号内含日期，因此详情查询只扫描对应日期的日志文件；编号非法、目录缺失或扫描超限都按未找到处理。

The event id contains the date, so detail lookup only scans log files for that date; invalid ids, missing directories, or scan caps are treated as not found.
