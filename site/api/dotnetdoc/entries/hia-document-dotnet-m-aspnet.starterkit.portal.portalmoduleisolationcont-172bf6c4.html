判定单模块失败是否可隔离：须已记录诊断、渲染循环已 `continue`、 且至少还有一个后续模块可继续渲染（否则无法证明"不整页失败"）。

Decides whether a single module failure is isolated: a diagnostic must be recorded, the render loop must have `continue`d, and at least one subsequent module must remain (otherwise "not blocking the page" is unprovable).
