Cross-layer readable/writable contract for an announcement module item.

remarks

该接口用于旧内容模块数据访问和 Web Forms 展示控件之间传递公告字段。实现只表达字段语义； 模块归属、链接安全、过期过滤和 HTML 编码由调用层各自负责。

This interface passes announcement fields between legacy content-module data access and Web Forms display controls. Implementations express field semantics only; module ownership, link safety, expiry filtering, and HTML encoding are owned by callers.
