返回当前动作人可见的协同事项事件时间线。

Returns the collaboration-item event timeline visible to the current actor.

Localized Fields

remarks

管理员读取所有事件；普通参与者只能读取工作流动作和参与者可见事件。查询只拼接固定受控 SQL 片段，事项标识始终作为参数传入。

Administrators read all events; ordinary participants read only workflow actions and participant-visible events. The query concatenates only fixed controlled SQL fragments, while the item identifier is always passed as a parameter.

params.itemId.summary

待读取的协同事项数据库标识；必须为正值。

Database identifier of the collaboration item to read; must be positive.

params.actorUserId.summary

由已认证调用方传入并在服务端重新解析授权的门户用户标识。

Portal-user identifier supplied by the authenticated caller and re-resolved for authorization on the server.

returns.summary

按发生时间和事件标识升序排列的可见事件；无效输入、无参与权、不在数据范围内、schema 不可用或读取异常时返回空集合且不泄露内部原因。

Visible events ordered by occurrence time and event identifier; invalid input, missing participation, out-of-scope data, unavailable schema, or read failure returns an empty collection without exposing the internal reason.
