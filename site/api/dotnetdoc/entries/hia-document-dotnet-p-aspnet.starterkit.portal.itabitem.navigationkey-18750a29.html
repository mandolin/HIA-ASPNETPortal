string ASPNET.StarterKit.Portal.ITabItem.NavigationKey { get; set; }

导航门控的稳定键；为空时门控回退到 `TabName`，保证历史部署零回归。 它与显示名解耦，因此显示名可以自由本地化而不改变 `Tab.*` 键。

Stable key for the navigation gate; when blank the gate falls back to `TabName`, keeping legacy deployments regression-free. It is decoupled from the display name, so the display name can be localized freely without changing `Tab.*` keys.
