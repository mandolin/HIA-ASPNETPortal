解析当前部署环境允许的模块 Profile 与模块包集合。

Resolves the module Profile and package set allowed by the current deployment environment.

remarks

P20.3 的解析器只读取 Web.config / 环境 JSON appSettings，不读取数据库设置表，也不提供在线启停能力。它表达“当前部署允许哪些能力进入门户”，模块状态表随后再表达“允许范围内是否启用”。

The P20.3 resolver reads only Web.config / environment JSON appSettings. It does not read the database setting table or provide online switching. It represents which capabilities this deployment allows into the Portal; the module state table then represents enablement inside that allowed scope.
