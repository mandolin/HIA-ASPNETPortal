remarks

该接口只负责存取 HTML 模块文本，不执行 HTML 白名单、净化或授权判断。当前阶段允许受信任管理员维护原始 HTML；未来若引入更细权限或净化策略，应在调用层统一接入。

This interface only stores and retrieves HTML module text; it does not perform HTML allow-listing, sanitization, or authorization. The current stage allows trusted administrators to maintain raw HTML; if later fine-grained permissions or sanitization policies are introduced, they should be attached at the calling layer.
