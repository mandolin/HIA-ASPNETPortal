Queries application projections with a controlled where fragment and parameters.

调用方只能传入本类固定的 where 片段；用户值必须通过参数传入。查询只返回列表/详情投影，不执行授权或输出编码。

Callers may pass only where fragments fixed by this class; user values must be parameters. The query returns list/detail projections only and performs neither authorization nor output encoding.
