remarks

只通过已登记定义读取（数据库覆盖 → appSettings → 代码默认），不直接读取原始配置键，也不判定任何授权。 任何解析失败都退回"不隐藏任何页签"的保守默认，确保配置错误永远不会把导航清空。 本类不缓存结果：底层 `PortalRuntimeSettings` 已按定义做受控解析，缓存失效策略由消费方（导航渲染层）决定。

Reads only through registered definitions (database override → appSettings → code default); it never reads raw configuration keys directly and never decides authorization. Any parse failure falls back to the conservative default of hiding nothing, so a configuration error can never empty the navigation. This class does not cache: the underlying `PortalRuntimeSettings` already resolves per definition, and the consumer (navigation renderer) owns cache invalidation.
