private void ASPNET.StarterKit.Portal.ImageModule.ApplyDimension(string configuredValue, bool isWidth)

把模块设置中的宽度或高度应用到图片控件。

Applies a configured width or height value to the image control.

Localized Fields

remarks

无法解析或小于 0 的值会被静默忽略，保留 Web Forms 图片控件默认尺寸，避免旧配置造成异常或布局破坏。

Values that do not parse or are below zero are ignored, preserving the Web Forms image control defaults and preventing legacy settings from causing exceptions or layout damage.

params.configuredValue.summary

来自模块设置的原始尺寸文本。

The raw dimension text read from module settings.

params.isWidth.summary

`true` 表示写入宽度，`false` 表示写入高度。

`true` applies the value as width; `false` applies it as height.
