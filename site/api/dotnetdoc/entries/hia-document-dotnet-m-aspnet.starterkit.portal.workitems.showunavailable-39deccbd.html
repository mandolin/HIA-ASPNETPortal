显示待办数据不可用提示，并清空列表。

Displays work-item data unavailable messages and clears the list.

Localized Fields

remarks

此方法只负责受控的页面呈现，不重新授权或访问数据服务。调用方只能传入已审查的操作提示，不能传入异常、连接或其他敏感实现细节；无论消息是否为空，均会清理旧摘要和列表，避免不可用状态下保留陈旧管理数据。

This method only performs controlled page presentation; it neither reauthorizes nor accesses the data service. Callers may supply only reviewed operational guidance, not exception, connection, or other sensitive implementation details; whether the message is empty or not, it clears the old summary and list so unavailable state cannot retain stale administration data.
