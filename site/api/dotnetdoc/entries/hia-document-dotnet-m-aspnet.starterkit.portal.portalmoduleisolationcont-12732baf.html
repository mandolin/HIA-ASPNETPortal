判定诊断记录字段是否齐备：EventId / Category / Message 非空、UtcTime 非零、 Message 含模块标识（`PortalDiagnosticEntry` 无 ModuleId 专用字段）、Category 在已登记词表内。 不新建第二套审计链 —— 词表由调用方传入。

Decides whether a diagnostic record is well formed: EventId/Category/Message non-blank, UtcTime set, Message contains the module id (`PortalDiagnosticEntry` has no dedicated ModuleId field), and Category is in the caller-supplied registered vocabulary. No second audit chain is created.
