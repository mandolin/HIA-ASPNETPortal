一个展示分组：稳定键、已本地化的显示名、供 `aria-controls` 使用的稳定容器 id，以及组内页签。 只渲染至少有一个页签的分组；空分组由 `NavigationView.EmptySectionCount` 计数留证，不输出空白 disclosure 按钮。

One presentation group: stable key, localized label, a stable container id for `aria-controls`, and member tabs. Only groups with at least one tab are rendered; empty groups are counted in `NavigationView.EmptySectionCount` as evidence rather than emitting blank disclosure buttons.
