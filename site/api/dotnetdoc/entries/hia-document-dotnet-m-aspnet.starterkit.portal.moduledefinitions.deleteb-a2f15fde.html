删除未被模块实例引用的历史模块定义。

Deletes a legacy module definition that no module instance references.

Localized Fields

remarks

引用数量大于零时拒绝删除，要求先禁用、迁移或显式清理实例。删除成功会写入运营审计；不会删除物理部署目录。

Deletion is refused when references exist, requiring instances to be disabled, migrated, or explicitly cleaned first. A successful deletion writes an operations audit and never deletes a physical deployment directory.
