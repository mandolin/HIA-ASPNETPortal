Data-access contract for Portal desktop and mobile-compatibility Tabs.

remarks

此接口仍承载旧门户 Tab 模型，包括分号角色串、移动端兼容字段和模块级布局关系。调用方在写入前应先完成后台授权、Tab 归属和历史字段兼容判断。

This interface still carries the legacy portal Tab model, including semicolon role strings, mobile-compatibility fields, and module-layout relationships. Callers should complete administration authorization, Tab ownership validation, and historical-field compatibility checks before writes.
