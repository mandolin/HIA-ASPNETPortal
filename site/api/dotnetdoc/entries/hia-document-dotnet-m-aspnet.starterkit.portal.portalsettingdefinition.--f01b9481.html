初始化一个不可变的系统设置元数据定义；仅保证稳定键非空，不在构造期解析默认值、验证来源或实施授权。

Initializes an immutable system-setting metadata definition; it guarantees only a nonblank stable key and does not parse default values, validate sources, or implement authorization during construction.
