remarks

此实现只写入请求和管理员处理状态，不直接修改员工主数据。员工主数据修改仍应通过员工目录后台或正式审批机制完成。读取路径在缺表或异常时软失败，写入路径返回低敏失败消息，详细异常由调用方按场景写诊断日志。

This implementation writes only requests and administrator review states. Employee master-data changes must still be performed through the employee-directory administration area or the formal approval workflow. Read paths fail softly when schema is missing or unavailable; write paths return low-sensitivity failures and leave detailed diagnostics to callers.
