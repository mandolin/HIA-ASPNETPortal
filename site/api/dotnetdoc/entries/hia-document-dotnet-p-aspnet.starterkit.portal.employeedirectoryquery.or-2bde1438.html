组织范围根节点的组织单元标识；为空表示不按组织过滤。该值只用于圈定查询范围，不授予任何组织访问权限。

Identifier of the organization unit that roots the query scope; null means no organization filtering. The value only bounds the query and grants no access to any organization.

Added in W68: it advances directory queries from an unbounded flat list to an organization-scoped query. Implementations must treat it as fail-closed: a non-positive identifier yields an empty set instead of degrading to a full scan.
