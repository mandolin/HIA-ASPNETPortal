是否在 CSS 中继承 Default 主题。

Whether the CSS inherits the Default theme.

remarks

当前仅是部署包声明性元数据。主题 CSS 必须自行显式表达继承关系；catalog 和 Master Page 不会据此自动加载或注入 Default 主题资源。

This is declarative deployment-package metadata only. Theme CSS must explicitly express inheritance itself; the catalog and Master Page do not automatically load or inject Default theme resources from this value.
