生成不依赖任何用户输入的物理存储文件名（GUID + 唯一允许扩展名）。

Generates a physical storage file name (GUID plus the single allowed extension) that depends on no user input.

remarks

Follows OWASP "generate the filename server-side, keep the user name as metadata only"; the attacker controls no landing path, eliminating overwrite, 8.3 short-name alias, and special device-name attacks.
