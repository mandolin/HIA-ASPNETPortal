class ASPNET.StarterKit.Portal.PortalModuleFormProfileGate

形态启用判定的**纯内存只读判定器**：把形态维度（宿主框架 / 入口形态）的启用判定 纳入"部署级允许集"这一输入，**显式缺省关闭**（允许集为空或未声明即不启用）、未知值 fail-closed。 **与装配态开关严格分离**：本类不读配置、不读文件、不引用装配态台账或 `AllowCodeFile`， 不接入 `PortalModuleProfileSnapshot.IsPackageAllowed` 装载链，不改变既有包解析 / Profile 判定结果。

Pure in-memory read-only gate for form-aware enablement: decides whether a form dimension (host framework / entry form) is enabled under a caller-supplied deployment-level allow-set, with an **explicit default-off** posture (an empty/undeclared allow set enables nothing) and fail-closed unknown values. It is **strictly separated from the assembly-state switch**: no config/file reads, no reference to the assembly ledger or `AllowCodeFile`, no wiring into `PortalModuleProfileSnapshot.IsPackageAllowed`, and no change to existing package parsing or profile decisions.

remarks

调用方负责从部署配置提取允许集并传入；本类只做判定，不负责配置解析。 允许集用精确比较（`StringComparison.Ordinal`），大小写与空白变体不自动放行。

Callers extract allow-sets from deployment configuration and pass them in; this class only decides. Allow-sets use exact (`StringComparison.Ordinal`) comparison — case and whitespace variants are not auto-allowed.
