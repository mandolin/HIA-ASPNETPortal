ASPNET.StarterKit.Portal.ImageModule

显示图片模块的受限图片资源。 图片展示模块用户控件的 Designer 字段容器；字段由 ASCX 服务器控件生成。

Renders the image module's constrained image resource. Designer field container for the image display module user control; fields are generated from ASCX server controls.

Localized Fields

remarks

该控件只消费模块设置中的图片地址和尺寸，不负责处理图片上传、外链白名单或二进制资源存储。地址必须先通过站内导航策略归一化，尺寸只能在可解析且非负时写入控件。

This control only consumes the image URL and dimensions stored in module settings. It does not handle uploads, external-link allow lists, or binary storage. The URL must pass portal navigation normalization, and dimensions are applied only when they parse to non-negative values.
