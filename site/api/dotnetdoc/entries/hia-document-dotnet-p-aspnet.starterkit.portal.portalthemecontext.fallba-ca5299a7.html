remarks

此字段描述影响最终全局主题选择的回退。无效 Tab 覆盖会告警并继续使用已解析的全局主题，当前不会在此字段追加候选链细节。

This field describes a fallback affecting the final global theme selection. An invalid Tab override warns and continues with the resolved global theme; the current implementation does not append candidate-chain detail here.
