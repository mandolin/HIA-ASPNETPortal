class ASPNET.StarterKit.Portal.PortalNavigationGroupView

主导航两级分组的展示视图模型：把「已完成授权过滤的页签集合」与 `PortalNavigationGroupAlias` 的封闭词表 结合，产出「分组 → 组内页签」以及「未分组平铺页签」的只读视图，供 `DesktopPortalBanner.ascx` 绑定渲染。 本类不读数据库、不读请求上下文、不调用 `PortalSecurity.IsInRoles` 或任何权限判定；分组只决定展示顺序与折叠归属， **绝不隐藏任何已授权页签**，也不改变 `PortalCfg_Tabs` 表结构（A 级硬边界）。

Presentation view model for two-level main-navigation groups: combines the already authorization-filtered tab collection with the closed vocabulary in `PortalNavigationGroupAlias`, producing a read-only "group → member tabs" view plus flat ungrouped tabs for `DesktopPortalBanner.ascx` to bind. This class reads no database or request context and calls neither `PortalSecurity.IsInRoles` nor any permission check; groups decide only presentation order and collapse ownership, **never hide an authorized tab**, and never change the `PortalCfg_Tabs` schema (class-A hard boundary).

remarks

与 `PortalNavigationGroupAlias` 的分工：后者是词表与配置覆盖的**数据契约**（fail-closed），本类是 **渲染数据装配**（保留每个页签在最终授权集合中的显示下标，因为 `PortalDesktopTabUrl` 的 `tabindex` 用它； 分组重排不得改变它，否则页面内匿名登录模块的注入启发式会漂移）。

Division of labour with `PortalNavigationGroupAlias`: the latter is the **data contract** for the vocabulary and configuration overrides (fail-closed); this class **assembles rendering data**, preserving each tab's display index in the final authorized collection because `PortalDesktopTabUrl` uses it for `tabindex`. Group reordering must not change that index, or the in-page anonymous-login injection heuristic drifts.
