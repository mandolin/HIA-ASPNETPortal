remarks

该契约继续支撑旧模块定义表；P3.2 之后的新模块来源应优先经过已验证的模块包目录。调用方在写入路径前必须完成受信任部署路径校验，删除操作也只应出现在 Legacy 管理入口中。

This contract still supports the legacy module-definition table; after P3.2, new module sources should preferably come from verified module package directories. Callers must validate trusted deployment paths before writing them, and delete operations should remain limited to the Legacy administration entry.
