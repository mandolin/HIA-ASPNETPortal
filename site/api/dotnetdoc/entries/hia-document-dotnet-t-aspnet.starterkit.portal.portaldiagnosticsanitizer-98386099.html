remarks

该工具遵循“宁可少记、不回退原文”的 fail-closed 原则，但不是唯一安全边界；调用者仍不得传入 Cookie、请求正文、表单值或认证票据。

This helper follows a fail-closed rule of omitting rather than falling back to raw text, but it is not the only security boundary; callers must still avoid cookies, bodies, form values, and authentication tickets.
