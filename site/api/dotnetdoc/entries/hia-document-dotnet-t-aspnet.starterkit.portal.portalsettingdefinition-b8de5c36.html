remarks

registry 定义设置契约；运行期可在受限数据库覆盖层、appSettings 与代码默认值之间解析。本类型只保存策略元数据，不读取真实来源、写数据库或实施页面授权；敏感设置值不应由该契约承载。

The registry defines the setting contract; runtime values resolve through a restricted database override layer, appSettings, and code defaults. This type stores policy metadata only: it reads no real source, writes no database, and implements no page authorization; sensitive setting values must not be carried by this contract.
