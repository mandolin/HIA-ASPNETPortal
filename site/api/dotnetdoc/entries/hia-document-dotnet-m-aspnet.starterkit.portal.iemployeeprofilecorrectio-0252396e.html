撤回本人提出的、尚在处理中的更正请求。

Withdraws a still-pending correction request submitted by the requesting user.

remarks

W69 新增。请求表状态受检查约束限定，因此撤回复用并把提交人记为操作人、在备注留痕，不引入新状态也不需要迁移。契约按 fail-closed 处理：用户标识或请求标识非正值、请求不存在、归属不符、状态已不是处理中，以及任何运行失败，都返回失败且不改变任何行；失败说明保持低敏，不回显他人请求细节。 Closed

Added in W69. Because the request table constrains status values, withdrawal reuses, records the requester as the actor, and leaves a note; no new status and no migration are needed. The contract is fail-closed: a non-positive user or request identifier, a missing request, an ownership mismatch, a status that is no longer pending, and any runtime failure all return a failure without changing any row. Failure explanations stay low-sensitivity and never echo another user's request details. Closed
