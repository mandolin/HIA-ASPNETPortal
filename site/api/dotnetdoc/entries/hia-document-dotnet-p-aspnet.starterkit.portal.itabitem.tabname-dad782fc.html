TabName

dotnet-property.NET
string ASPNET.StarterKit.Portal.ITabItem.TabName { get; set; }

桌面端导航中展示的页签名称；多语言体系下它同时是**中文列**与**默认回退列**，因此永不置空。 改名或本地化都不会影响门控稳定键，稳定键由 `NavigationKey` 承载。

Tab name displayed in desktop navigation; within the multilingual scheme it is also the **Chinese column** and the **default fallback column**, so it is never blank. Renaming or localizing it never affects the gate stable key, which `NavigationKey` carries.
