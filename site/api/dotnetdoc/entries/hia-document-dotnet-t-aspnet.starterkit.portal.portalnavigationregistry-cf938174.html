remarks

注册表只发布可审查的导航元数据和显示依赖；它不读取当前用户、模块状态或部署配置，也不执行路由和授权。消费方必须在显示或访问入口时独立完成实际检查。

The registry publishes reviewable navigation metadata and visibility dependencies only; it reads no current user, module state, or deployment configuration and performs no routing or authorization. Consumers must complete actual checks independently when showing or accessing an entry.
