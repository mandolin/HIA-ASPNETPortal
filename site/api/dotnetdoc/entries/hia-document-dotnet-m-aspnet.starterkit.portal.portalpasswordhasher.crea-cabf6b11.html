以显式迭代次数创建强哈希；当调用方需要根据已保存凭据记录复用其成本参数时使用（例如验证流程读回迭代次数）。

Creates a strong hash with an explicit iteration count, used when the caller must reuse a saved credential record's cost parameter (for example, when verification reads the iteration count back).
