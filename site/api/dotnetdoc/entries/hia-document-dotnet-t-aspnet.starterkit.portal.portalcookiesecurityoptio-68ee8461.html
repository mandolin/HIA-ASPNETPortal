Transport-security attribute decision result for identity and role cookies.

remarks

该对象只承载决策结果，不创建、不写入也不读取任何 Cookie；Degraded 与 DegradeReason 仅用于诊断，且不含凭据、票据或路径等敏感内容。

This object carries decision results only and never creates, writes, or reads cookies; Degraded and DegradeReason exist for diagnostics and contain no credential, ticket, or path data.
