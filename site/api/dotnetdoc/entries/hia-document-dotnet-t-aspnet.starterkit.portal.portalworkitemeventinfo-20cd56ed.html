remarks

本类型面向后台列表、审计辅助和排错展示，只描述某次查询看到的历史事件，不自动反映并发写入。授权判断仍应使用当前用户、角色和业务对象状态，而不是反向依赖历史投影；字符串未按 HTML 上下文编码，展示方必须授权并编码。

This type is intended for administration lists, audit assistance, and troubleshooting displays. It only describes historical events observed by one query and does not automatically reflect concurrent writes. Authorization decisions must still use the current user, roles, and business-object state rather than historical projections. Strings are not HTML-context encoded, so renderers must authorize and encode them.
