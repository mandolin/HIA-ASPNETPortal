发起在线能力包上传（第一步）：把包送入隔离暂存区并触发校验。与「确认安装」分离，且不与 `Module.Catalog.Edit`（启停已部署包）、`Module.AssemblyState.Edit`（装配态声明）、`EnterpriseCapability.*`（能力层治理）混用。 **A 级硬边界**：本键只表达「谁能发起上传」，不因包的来源声明或 `module.json` 中的 capability 字段自动授予； 经此通道安装的第三方模块不得因此获得 `Admins` 角色，也不得自创能力条目。

Initiate an online capability package upload (step one): send the package into the isolated staging area and trigger validation. Separate from "confirm install" and distinct from `Module.Catalog.Edit` (enable/disable deployed packages), `Module.AssemblyState.Edit` (assembly-state declarations), and `EnterpriseCapability.*` (capability-layer governance). **A-level hard boundary**: this key expresses only "who may initiate an upload"; it is never granted automatically from a package's origin claim or the capability field in module.json. A third-party module installed through this channel must not gain the `Admins` role or create capability entries of its own.
