remarks

本类型只承载判定所需的只读证据：不读取数据库、不推断角色继承、不缓存跨请求状态。组织范围集合为空表示"范围未知或没有任何组织范围"，此时组织维度不得授予可见性（fail-closed）。

This type carries only read-only evidence for the decision: it reads no database, infers no role inheritance, and caches no cross-request state. An empty organization-scope collection means "scope unknown or no organization scope at all", in which case the organization dimension must not grant visibility (fail-closed).
