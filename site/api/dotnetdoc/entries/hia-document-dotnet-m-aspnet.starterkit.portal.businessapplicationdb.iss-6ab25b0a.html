检查申请表和流程事件表是否同时可访问。

Checks whether both the application and workflow-event tables are accessible.

Localized Fields

remarks

这是一次可用性探测，不证明后续写入成功，也不执行业务授权；表缺失、元数据查询失败和连接异常均按不可用处理。

This is an availability probe. It guarantees neither a later successful write nor business authorization; missing tables, metadata-query failures, and connection errors are treated as unavailable.

returns.summary

两个受控表均可访问时为，否则为。 true false

when both controlled tables are accessible; otherwise. true false
