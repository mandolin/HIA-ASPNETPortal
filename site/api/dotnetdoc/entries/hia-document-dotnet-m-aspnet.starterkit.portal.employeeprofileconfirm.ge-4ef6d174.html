把当前登录身份解析为门户用户标识。

Resolves the current sign-in identity to a Portal user identifier.

This currently uses the legacy `UsersDb.GetSingleUser` lookup by sign-in name; employee-code sign-in still maps back to a Portal user identifier.

门户用户标识；无法解析时返回 `0`。

Portal user identifier, or `0` when it cannot be resolved.
