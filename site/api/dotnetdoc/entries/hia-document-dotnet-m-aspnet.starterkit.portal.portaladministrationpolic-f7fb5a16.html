校验可选多行文本（用于"其它语言" JSON 列）：允许空、允许换行，但不允许控制字符，并限制长度。

Validates optional multi-line text (used by the "other languages" JSON column): blank and newlines are allowed, while control characters are not and a length limit applies.

Localized Fields

remarks

JSON 列必须允许换行：管理员会为了可读性把它格式化后再粘贴，用单行校验会把合法 JSON 拒掉。 但换行只放开 `\r` 与 `\n`，其余控制字符仍拒绝 —— 控制字符会让 JSON 校验与后续诊断都变得不可读。

The JSON column must allow newlines: administrators format it for readability before pasting, and single-line validation would reject valid JSON. Only `\r` and `\n` are permitted though; every other control character stays rejected, because such characters make both JSON validation and later diagnostics unreadable.
