主导航分组配置别名覆盖文本；由 `PortalNavigationGroupAlias` 严格解析，非法值 fail-closed 回退默认词表， 绝不隐藏页签。该值只影响展示分组，不参与授权判定，也不改变 `PortalCfg_Tabs` 表结构。

Main-navigation group configuration alias override text; parsed strictly by `PortalNavigationGroupAlias`, with invalid values failing closed back to the default vocabulary so no tab is ever hidden. The value affects presentation grouping only, takes no part in authorization, and does not change the `PortalCfg_Tabs` schema.
