remarks

本实现维持旧 Web Forms 门户的页签排序、角色串和移动端字段兼容性；写入后会刷新内存快照，避免同一请求生命周期内继续读取旧集合。

This implementation preserves the legacy Web Forms portal tab ordering, role-string and mobile-field compatibility; write operations refresh the in-memory snapshot so later reads in the same request do not use stale collections.
