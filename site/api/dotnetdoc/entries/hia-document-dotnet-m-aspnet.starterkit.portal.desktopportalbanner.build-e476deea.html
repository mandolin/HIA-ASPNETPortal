按当前界面文化解析页签显示名（中文列 / 英文列 / 其它语言 JSON 列）。

Resolves the tab display name by the current UI culture (Chinese column / English column / other-languages JSON column).

Localized Fields

remarks

页签名本地化前，这一行就是 `boundTab.TabName`；本地化后必须经解析器，否则英文界面会显示中文页签名。 解析器内部降级到中文列，因此这里不再判空 —— 但**门控键不走本方法**，键仍由 `NavigationKey` 派生， 否则"同一个页签在不同语言下键不同"会让 registry 失配。

Before tab names were localized this line was simply `boundTab.TabName`; afterwards it must go through the resolver, or an English UI would show Chinese tab names. The resolver degrades to the Chinese column internally, so no blank check is needed here — but the **gate key never goes through this method**: the key still derives from `NavigationKey`, otherwise "the same tab having different keys per language" would break registry matching.
