class ASPNET.StarterKit.Portal.PortalNavigationEntryRenderer

把入口可见性策略接入 Admin 页头动作区的渲染器（Web 侧组装上下文，策略本身仍在组件层）。

Renderer that connects the entry visibility policy to the Admin page header action area (the web side assembles the context while the policy stays in the component layer).

Localized Fields

remarks

本类型只输出导航类入口；页面自身的写库主操作（新增用户、新增角色、新增 Tab 等）与既有服务器控件由页面自身保留，不在本渲染器范围内。可见入口为 0 时返回空字符串，使动作区容器整体不渲染。

This type emits navigation entries only; page-owned persistence actions (add user, add role, add tab) and existing server controls stay owned by the page and are out of scope. When no entry is visible it returns an empty string so the action container is not rendered at all.
