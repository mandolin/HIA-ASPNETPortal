remarks

动态控件不由常规页面容器构造，因此显式请求成员注入。派生类只有在调用 base.OnInit 后才能依赖该属性；服务只负责读取设置，不证明模块或用户授权。

Dynamic controls are not constructed by the normal page container, soexplicitly requests member injection. A derived class may depend on this property only after calling base.OnInit; the service only reads settings and proves neither module nor user authorization.
