remarks

角色名称仍写入旧的分号授权字符串；改名会同步更新当前门户的 Tab 访问角色和模块编辑角色。 删除存在成员或授权引用的角色会被拒绝，不执行隐式清理。

Role names remain stored in legacy semicolon authorization strings; a rename synchronizes current Portal Tab-access roles and module-edit roles. Deleting a role that has members or authorization references is rejected without implicit cleanup.
