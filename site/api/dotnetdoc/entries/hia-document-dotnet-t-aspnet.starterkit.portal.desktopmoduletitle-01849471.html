remarks

P7.4 起标记从旧 table 标题栏切换为语义化容器；权限判断和编辑链接生成仍沿用旧模块配置。

Starting with P7.4, the markup changes from the legacy table title bar to semantic containers, while permission checks and edit-link generation continue to use the legacy module configuration. P8.3 further separates the title and action areas so themes can style module actions consistently.
