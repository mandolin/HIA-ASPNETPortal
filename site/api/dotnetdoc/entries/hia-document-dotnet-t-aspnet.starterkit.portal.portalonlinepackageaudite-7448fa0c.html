class ASPNET.StarterKit.Portal.PortalOnlinePackageAuditEvents

在线能力包审计的稳定事件词表：分类、动作、目标类型与结果值。写入统一经既有 `PortalOperationAudit.Record` 落入 `PortalCfg_OperationAudits`，因此本类只定义键名，不实施写入、不连接数据库。

Stable audit event vocabulary for online capability packages: category, actions, target type, and outcome values. Writes go through the existing `PortalOperationAudit.Record` into `PortalCfg_OperationAudits`, so this class only defines key names; it performs no write and connects to no database.

remarks

放在 `Portal.Components` 而非 Web 项目，是为了让 Web 层、门禁与单测共享**同一份**常量定义， 避免两份字符串漂移；既有 `PortalOperationAuditEvents` 仍在 Web 项目维护其历史词表，两类互不覆盖。 **工具不代写**：离线工具只生成可审阅产物，不调用本类写入；审计记录由运行期在审批通过后完成。 **A 级硬边界**：TargetId 只用服务端生成的隔离暂存名，不用包内声明的包标识、来源或 capability 作为授权或身份依据。

It lives in `Portal.Components` rather than the Web project so the Web layer, gates, and unit tests share **one** definition and cannot drift across two copies of strings; the existing `PortalOperationAuditEvents` keeps its historical vocabulary in the Web project and neither class overrides the other. **Tools never write on behalf of runtime**: offline tools only emit reviewable artifacts and never write through this class; audit records are produced at runtime after approval. **A-level hard boundary**: TargetId uses only the server-generated isolated staging name, never a package-declared id, origin, or capability as an authorization or identity basis.
