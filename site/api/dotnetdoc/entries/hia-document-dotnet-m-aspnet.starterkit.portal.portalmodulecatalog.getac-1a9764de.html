获取当前前台门户 Tab 中已启用受信任模块包的 CSS 候选。

Gets CSS candidates for enabled trusted module packages in the current front-end portal Tab.

Localized Fields

remarks

本方法消费已完成路径、Profile 和状态 gate 的运行描述符，只输出受信任且已启用包的 manifest CSS 资源候选。它不重新校验 manifest、不注入 link 标记、不加载控件、不实施导航或页面授权；实际 Head 注入由 Master Page 的独立边界负责。

This method consumes runtime descriptors that have already passed path, Profile, and state gates, and outputs candidates only for manifest CSS resources of trusted enabled packages. It does not revalidate manifests, inject link markup, load controls, enforce navigation, or enforce page authorization; actual Head injection belongs to the Master Page's separate boundary.

params.context.summary

可选 HTTP 上下文；未提供时使用当前上下文，二者均不可用时返回空只读集合。

Optional HTTP context; the current context is used when omitted, and an empty read-only collection is returned when neither is available.

returns.summary

按活动 Tab 顺序保留首次出现项、大小写无关去重的站内 CSS 候选只读集合；后台请求、无活动 Tab 或解析期间受控异常可能返回空集合，受控异常发生前已累计的候选会被保留。

Read-only site-local CSS candidates that retain first occurrence in active-Tab order and are de-duplicated case-insensitively; administration requests, no active Tab, or a controlled resolution exception can return an empty collection, while candidates accumulated before a controlled exception are retained.
