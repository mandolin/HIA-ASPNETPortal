{%- comment -%} Controlled override of the just-the-docs `components/site_nav.html` (C-anp-P22, W-anp-P148). WHY (two changes, both required): 1. **Cache key**: upstream is included via `include_cached` with no parameters, so Jekyll reuses one rendering for the whole site. The paired `sidebar.html` override now passes `lang=page.lang`, which makes the cache per-language. 2. **Language filtering**: `site.html_pages` contains BOTH language trees, so without filtering the sidebar mixes Chinese and English nodes. This override filters the page set by the requested language: Chinese pages are those whose URL does not start with `/en/`, English pages those that do. Everything else is copied verbatim from just-the-docs v0.12.0. When upgrading the theme, re-diff this file against upstream. {%- endcomment -%} {%- assign nav_lang = include.lang | default: page.lang -%} {%- if nav_lang == 'en' -%} {%- assign nav_pages = site.html_pages | where_exp: "item", "item.url contains '/en/'" -%} {%- else -%} {%- assign en_pages = site.html_pages | where_exp: "item", "item.url contains '/en/'" -%} {%- assign nav_pages = "" | split: "" -%} {%- for item in site.html_pages -%} {%- assign is_en = false -%} {%- for ep in en_pages -%} {%- if ep.url == item.url -%}{%- assign is_en = true -%}{%- break -%}{%- endif -%} {%- endfor -%} {%- unless is_en -%}{%- assign nav_pages = nav_pages | push: item -%}{%- endunless -%} {%- endfor -%} {%- endif -%}
