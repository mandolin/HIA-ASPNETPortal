{%- comment -%} Controlled override of the just-the-docs `components/sidebar.html` (C-anp-P22, W-anp-P148). WHY: upstream calls `{% include_cached components/site_nav.html %}` with **no parameters**. Jekyll's `include_cached` keys its cache **only on the parameters**, so with none the navigation is rendered once and reused for the whole site — identical on every page regardless of language. This site is bilingual (Chinese at the root, English under /en/), so a shared cache necessarily mixes both trees in one sidebar. THE ONLY CHANGE: pass the page language as a cache key (`lang=page.lang`), which makes the cache per-language while still benefiting from caching. Everything else is copied verbatim from just-the-docs v0.12.0. When upgrading the theme, re-diff this file against upstream. {%- endcomment -%}
